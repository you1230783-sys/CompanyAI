LM_AI

本機資料

對話在此 Windows 使用者下加密保存。登出會保留歷史；開啟舊對話後，只有再按送出才會傳給目前登入的帳號。刪除功能位於對話右上角。 伺服器端仍會儲存已送出的對話、附件及任務資料；刪除本機資料或移除任務卡片不會刪除伺服器端的紀錄。

必須更新 LM_AI

目前版本已停止支援。安裝更新完成前，功能暫時停用。
