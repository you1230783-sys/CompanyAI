## 本版修改

- 所有 HTML 對話框按鈕加入實心底色及邊框，主要操作保留強調色，支援亮／深色、停用及鍵盤焦點。
- 圖表編輯分為基本設定、座標轉換、顏色與參考線三頁。上下方向仍為實體 X／Y；切頁不清除內容，套用時跨頁驗證，錯誤會切回相應頁。可用左右鍵及 Home／End 切頁；內容獨立捲動，套用列保留。
- 每頁有可展開的「？」說明，含平移、重新編號、五點缺值範例及參考線方向。範例為固定假資料，不使用公司資料。
- X／Y 自動範圍各自計算目前轉換、篩選後的所有系列。忽略缺值與明確略過的點；數值按最大絕對值的量級，以5為格線單位向外取整，例如12～23 → 10～25、0.12～0.23 → 0.10～0.25。同值向兩側留白；類別軸取首末位置，單類別不設定相等上下限。這是填入範圍的操作，不會修改來源數值。
- 參考線文字空白時明確隱藏標籤，不補座標數字；PNG 與畫面共用設定。游標提示同時顯示 X／Y，水平長條使用實體軸，類別顯示原標籤，名稱經 HTML 跳脫。
- Python 連續失敗上限10次、其餘工具共同5次；成功只重設同類計數，穿插另一類不清除失敗。已辨識原生工具的非嚴格參數錯誤及交付檢查也計入。失敗不另外增加無進展計數，但也不假造進度或清除原計數。重播／成功卻無新結果仍保留8次無進展保護。
- 計數隨加密 checkpoint 保存，自動整理不歸零；到上限暫停保留進度，使用者明確續接才重設。無法辨識回覆仍走既有格式修復上限，未知提交、嚴格 Schema、權限與身分錯誤的處理不放寬。
