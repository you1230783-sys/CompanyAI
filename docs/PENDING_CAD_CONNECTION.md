# 待發行：CAD 開啟／重連

使用者回報：任務中開啟 CAD 或手動開啟後重新連線仍失敗，停止任務、先開 CAD 再開始才成功。尚未取得此次失敗診斷，不能斷言所有失敗的唯一原因。

已確認舊流程先用短命 worker 做 connect／launch，再結束程序、用第二個 worker 重取 GetActiveObject 才執行。啟動所得 COM 物件沒有沿用，造成就緒／ROT 登錄時間差的風險。改為每次嘗試在同一 worker 連線並完成既定計畫，維持同一 app 物件；不重新要求模型產生或重送整個任務。

- 初次只取得已開啟物件。使用者選擇開啟才允許 CoCreateInstance，且先嘗試既有物件；每次明確開啟選擇最多啟動一次。
- 使用者重連後，對明確的物件尚未登錄／COM 忙碌回應，每0.5秒重試，重試窗口15秒。這不是 COM 單次呼叫的硬性逾時；原生 worker 取消／240秒期限仍適用。
- 就緒等待只涉及連線及身分讀取，不重播建立文件或繪圖。已取得 app 時不再建立或改連另一個 app。
- 未開始操作的 connect 失敗才回原提示，保留計畫及選定版本；已部分操作仍依原復原規則，絕不直接接續重播。
- 報告新增 connection.same_worker／attempts／launch_attempted／last_hresult，以利確認啟動或重連問題。

本批僅修改原始碼，未重建runtime、未測試、未編譯打包或推送。下次發行前補：初始未開、使用者啟動、手動重連、已開不重啟、忙碌重試、逾時取消、版本固定及部分繪圖不得重播。公司實機待驗。
