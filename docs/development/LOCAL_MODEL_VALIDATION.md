# 本機真實模型驗證流程

## 長期採用的原則

使用者於2026-10-18授權建立並保留此流程，供後續修改反覆驗證。本機以Strata模擬公司AI，逐輪只提供應用程式真正送出的上下文及工具；保留模型原始參數，不由測試程式替模型補正。模型自述身分不能證明來源，本機通過仍須公司模型及環境抽驗。

## 三級範圍

| 等級 | 真實模型驗證範圍 | 使用時機 |
| --- | --- | --- |
| 完整 | 每類已支援功能、正常與失敗路徑、長上下文、取消／恢復及跨功能任務 | 發版前、架構調整後 |
| 代表性 | 每類挑重要的完整任務 | 共用流程或跨模組修改後 |
| 重點 | 本輪修改的功能及依賴流程 | 局部修正後 |

每級均保留訊息送出、工具呼叫解析、取消與成果交付的基本檢查。程式契約測試與真實模型端到端測試分別記錄，不能互相冒充。

## CAD：一般使用者與多種圖面

- 初次需求採一般使用者口吻，不先交付座標、圖元種類、工具格式或完整加工尺寸。AI詢問必要條件時，以預先保存的使用者角色資料回答；不替模型選工具、算座標或修改參數。
- 每案、每CAD版本使用獨立專案／對話。涵蓋浴室置物架、門背掛架、桌下收納、陽台花架、多層住宅、小工廠及較大混合機台廠區；避免只對同一法蘭板調校。
- 每案先保存初始要求、角色補充、模型／程式版本及時間。追問不等於失敗；合理採用假設時，核對是否明示假設及未確認事項。
- 逐案經正式runner、Broker及鎖定的CAD worker執行，2008／2022串行，避免共享CAD狀態互撞。命令列批次驗證須明示不涵蓋GUI控制項；GUI另保留代表案例。
- 失敗保留原圖、報告及原始回覆，不覆寫、不自動重畫同案。真正需要新嘗試時建立新編號，保留原案結果。部分執行、結果未知或不支援時依既有停止規則處理。
- 工具成功後另開本案DWG唯讀核對單位、幾何、原生標註／文字、類型數量、保存及重新開啟狀態。模糊需求不強套固定座標答案；按實際使用者條件及模型明示假設評估。
- 住宅／工廠僅作配置討論；不將缺乏現場條件、結構／消防／逃生驗證的示意圖稱為施工或加工核准圖。大型案若碰到目前操作數／新增能力上限，應列出實際限制，不能縮減內容後宣稱完成。

## 判定與證據

每案分別記錄模型行為、工具執行、獨立資料核對及外觀。狀態使用：通過、資料通過但外觀待驗、失敗、待必要補充、不支援、未測及環境不足。沒有產物不能只因模型說完成就判通過；幾何正確也不能掩蓋錯誤答案。

保留輪數、輸入／輸出token、模型時間、工具時間及整體時間；人工等待不混算成推論速度。相同重要案例換資料重跑，不以一次成功宣稱穩定。

輸出額度與上下文容量分別記錄。2026-10-18使用者要求將Strata測試每輪輸出上限提高到20,000，接近公司設定；轉接公告的上限／預設值及實際模型請求須一致，128K上下文不變。思考模式另外記錄，部分模型的思考也計入completion額度。提高tokens不等於放寬CAD每批100項操作，也不能當作已完成圖面的證據。

## 公司與本機的差異

Outlook真實帳號及企業加密軟體目前需公司實測；模擬信件／權限錯誤必須標記模擬。其他待確認項包括公司模型中介、憑證／限流、Office／CAD／COM／字型版本、網路磁碟與檔案占用、外掛及真實複雜資料。不能把模擬通過當成以上環境已驗收。

測試連線、Token、聊天及DWG放忽略的`.build`，不放進Git、教學或正式安裝包。沒有本輪發行授權時，不進版、更新dist或推送。

## CAD批次入口

1. 按專案v142指引重新鎖定CAD runtime，完成必要建置／契約驗證，再建置`cad_model_suite` example；不可讓新EXE搭配舊runtime。
2. 使用新的隔離目錄、localhost連線與`tools/run_cad_user_cases.py --pause-for-visual`。原始案例在`tools/cad_user_cases.json`；每次保存EXE、runtime及輸入檔雜湊。
3. 角色最多回答兩次必要補充；若真的詢問另開或既有文件，明確選另開，不提供修改其他文件的同意。可選偏好使用正式Inbox，模擬一般用戶回答「依原條件安排概念圖，未量條件仍待確認」，不增加座標或現場數據。輸出額度暫停可沿同一run的正式檢查點續接兩次，不新開任務代替續接。依實際pause_reason區分輸出額度與回覆修復上限，不把所有暫停都標為`PAUSED_OUTPUT_LIMIT`。
4. `tools/verify_cad_user_case.py`逐份重開本案全部已交付DWG，先比對原生selected.progid與要求版本，再核對單位、原生尺寸、保存與部分案例數量。多產物的獨立快照與報告保存在artifact-verifications，不只挑最後一份；任一錯版或資料問題都須保留。錯版產物只在實際建立它的CAD唯讀覆核，標記WRONG_CAD_VERSION，不拿另一版能重開當成指定版本建圖通過。驗收工具的純資料與續跑測試為`python tools/test_cad_user_verification.py`。此工具是子集檢查，不能取代人工對照要求、安裝條件、圖面排版及實際CAD視覺覆核。
5. 確實查看圖面後，保存個案`visual-review.json`（PASS／ISSUES／UNREADABLE、觀察與限制）。有問題不能以資料通過蓋過；成功才關閉已知測試文件，不儲存驗證期間的視野調整。
6. `stop-after-case`可在案例邊界停止更換候選版；部分圖面保留，不中斷未知寫入，不自動重畫。使用`tools/summarize_cad_user_cases.py`整理原始往返，分開報告每批候選及失敗原因。

同候選在案例邊界停止後，可使用原本參數加`--resume`續跑。工具核對EXE雜湊、runtime manifest雜湊、完整案例與版本，並要求既有案例已逐份資料／畫面覆核、DWG雜湊未變；不重送結果未知的任務，也不覆寫未完成案例。舊manifest缺少雜湊時不能隱含信任或自動借用；本輪舊批次是在比對啟動時凍結candidate與全部runtime檔案後才補欄位，原manifest與補充證據另存。
## CAD分階段規劃（0.8.69以前的歷史）

輸出額度包含模型計入的思考tokens；20,000不是必須用完的目標，也不能只靠加大額度處理無工具輸出的長時間生成。複雜新圖先集中詢問必要條件，再以`compact_context`保存200–400字的具體配置、主要尺寸、構件數量、假設及操作數估算，下一輪沿用方案產生完整計畫。簡單任務不增加空回合。

`compact_context`保存文字，沒有分段累積繪圖參數的能力；`cad_draw`每次建立獨立新圖，不能將幾何、尺寸、樓層分次呼叫當成同一圖的追加。100項操作限制仍適用。若完整計畫的生成仍耗盡額度，須如實記錄，另評估程式端儲存分段計畫，不能將短方案回覆算成CAD成功。

實測須記錄：是否先詢問必要條件、是否交出短方案、是否沿用方案、各輪耗時／tokens／停止原因、原生繪圖與獨立資料及視覺核對。提示詞不會強制切斷內部思考時間；一次成功也不能證明穩定解決。

文字提示候選8784已在住宅2008交出短方案及完整88操作，沒有用盡20k，但規劃仍耗16,212 tokens／423.554秒，且有必要條件未詢問、缺原生尺寸與錯誤失敗說明，不能稱整案通過。後續候選由程式保存規劃狀態：fresh cad-new先不公告cad_draw的完整Schema，成功compact_context後再公告。簡單新圖僅記1–2句方案；舊checkpoint維持相容，不恢復任何目前文件寫入授權。必須檢查實際線上請求的工具清單，不能只看提示文字聲稱有分階段。

原生資料錯誤與模型問題分別驗證。Big5尾碼0x5C須以DBCS完整字元輸出，不能關閉JSON驗證或把錯誤資料當空圖；相容性修正以兩版原生字串及完整快照核對證明。模型把saved=false誤說成未建立時，也須保留實際drawing_started／completed_operations，不讓自然語言覆蓋原生狀態。

## 0.8.70：同圖分段累積的驗證

新建CAD的正式流程為短方案→cad_plan_start→多次cad_plan_part→cad_plan_commit。每段1–20項、最多40段／400項／500KB；所有段只保存在本機計畫，commit時才由原生工具一次建立同一張DWG。必要修正先inspect指定段，再以最新plan_revision及相同part_id替換，不重送整圖。

每輪核對程式目錄的計畫ID、版本、區段ID與累積數量，確認整理上下文後仍保留；精確參數以checkpoint／指定段查回，不由模型摘要重建。另常駐最近新增或查回的四段精確資料，合計最多32KB，避免只保留最近一次查詢而在牆線／家具間互查；近期工具歷史仍含當輪參數。只有未完整列在工作集的段才公告inspect選項。單元測試涵蓋保存還原、過期拒絕、去重、局部替換、大小上限與取消未繪圖。

真模型必須實際交出多段、每次不超20項、commit只送識別碼與版本、最後一份DWG存檔重開；記錄length輪數、單輪最大輸出及累計輸出，不能只因模型聲稱有分段就通過。完成結果只送有界摘要，完整原生報告留本機，並核對警告／量測不可用計數未遺失。

分段傳輸、原生繪圖、獨立資料與設計品質分開判定。模型仍可能把不同樓層文字放錯座標、漏尺寸或忽略門口；這些不能因分段成功而改判通過。既有公司服務、GUI與通知等未測範圍不擴大。
