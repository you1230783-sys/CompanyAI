# 專案介面調整（已納入 0.8.17）

狀態：本文件保留先前 UI 調整的設計與當時驗證紀錄。使用者後續已授權將這批修改納入 0.8.17 EXE 並推送 Git；最新交付範圍及驗證以 [0.8.17 紀錄](VALIDATION_0_8_17.md) 為準。

## 互動

- 專案進度、全域狀態、一般浮動提示與模型提示共用右上角通知，位於通知／任務圖示下方；三秒後隱藏。相同狀態重繪不重新計時。
- 移除左上常駐狀態列，該處改放目前專案根目錄；一般對話及其他頁面不顯示路徑。停止專案任務按鈕保留於輸入區，不依賴浮層。
- 側欄列為「專案名稱、＋新對話、齒輪」。齒輪開啟設定：修改名稱、匯入文字、清除既有匯入文字、移除專案。
- 移除先詢問對話去向：移到一般對話或一併刪除對話，亦可取消。只操作本機對話與授權管理紀錄，不刪專案資料夾、原檔或已產生的成果。
- 匯入使用 Windows 原生選檔，從專案資料夾開始，僅接受專案內 TXT／MD；原生層仍檢查邊界與檔案身分。檔名唯讀，全文輸入框加上邊框及「複製文件全文後，貼在這裡…」提示。
- 移除操作畫面中的 DPAPI、編碼、子程序等工程解釋，維持簡短成功／失敗訊息。授權及原檔保護仍沿用既有契約。

## 本輪驗證

- 使用專案環境腳本初始化 v142：MSVC 14.29.30133、實際 cl 19.29.30159 x64。
- `cargo check --frozen --all-targets`、Rust 格式與全部自有 UI JavaScript 語法檢查通過；未執行發行建置腳本。
- 本機無頭 Edge 開啟實際 HTML／CSS／JavaScript，以虛構狀態檢查通知位置與三秒隱藏、重繪不延長時間、專案路徑顯示／隱藏、停止按鈕、改名提交、選檔回覆關聯、匯入表單、移除的兩個選項，以及 VNC 對話框開關與取消要求。
- 已檢視聊天、匯入、VNC 對話框的本機預覽截圖。預覽不使用公司帳號；品牌 ICO 由 EXE 內嵌提供，直接開 HTML 的預覽沒有該資源。
- 原生選檔與本機對話刪除的完整執行、真實 VNC 網站登入／登出，以及公司加密與模型環境，留待下一次 EXE 建置及公司實測；本輪不宣稱這些驗收通過。
