# 待發行：一張一般對話教學與簡短更新摘要

使用者要求先看初階卡牌效果；本批不進版、不編譯、不打包、不推送。Cargo版本維持0.8.64，下一版預定0.8.65。未執行測試或UI預覽，待下次交付補驗。

## 初階教學

- 登入完成、未受版本門檻阻擋、沒有工作與其他對話框時自動顯示。每次啟動最多自動顯示一張；若有更新摘要優先顯示，教學保留至下次啟動。
- 一張卡、三個簡短步驟：描述需求、需要時附檔、看完再追問。沒有實際送出訊息或修改資料。
- 「開始使用」記錄完成；「稍後再看」、Escape或點外部只關閉本次。設定→一般→使用教學可隨時重看，不必清檔。
- EXE旁 onboarding-state.json 的 tutorials.chat.basics=1 是此卡版本。刪除此key或改0，重新啟動登入後可重測自動出現。不要為了重看教學刪除更新紀錄。
- 設定檔無法讀寫會明示錯誤，不靜默改存其他路徑或覆寫損壞資料；仍可手動重看。自檢模式不寫入正式教學紀錄。

## 更新摘要

- assets/release-notes.json 保存簡短區塊／條目／版本，從0.8.65開始；未來只有使用者要求才新增教學，發行摘要另由維護者記錄。
- 更新前應用記錄目前版本；NSIS在替換前讀取舊EXE的版本，安裝成功後寫入EXE旁update-transition.ini，讓0.8.50等尚無旗標的舊版也能取得真實更新起點。首次全新安裝沒有舊版本，不假稱更新。
- 篩選舊版 < 公告版本 <= 當前版本，且公告版本>=0.8.65，依區塊條列並標註版本。跨版時保留尚未確認的更新起點，按「知道了」才清除。
- 不回填0.8.64以前的公告，不把版本差異推測成不存在的功能。手動覆蓋來自不支援紀錄的舊EXE時，沒有可靠舊版來源就不捏造更新起點。
- 下次發行需驗證：首次登入、重看、稍後、登出關閉、旗標寫入失敗、跳版、同版重裝、回復失敗與原紀錄保留。現有安裝生命週期驗證仍未執行。

## CAD 引線排版

舊版原生MText明確使用左下錨點AttachmentPoint=7，接著再將InsertionPoint設於水平線上方1mm；字高3、Rotation=0。普通Text明確左對齊，避免繼承中間對齊；上述屬性納入存檔前後核對。仍保留原生引線，未改成線段假圖元；2008／2022屬性相容性與實際外觀待驗。

依據：[AttachmentPoint](https://help.autodesk.com/cloudhelp/2026/DEU/AutoCAD-ActiveX-Reference/files/GUID-FD7EDA56-7FA0-4616-A746-9B97AE0C6456.htm)、[枚舉值](https://developer.bricsys.com/bricscad/help/en_US/V22/DevRef/source/Constants_AcAttachmentPoint.htm)。本修正不等於已具備全圖自動避讓排版。
