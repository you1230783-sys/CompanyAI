# 登入入口與彈窗關閉（已納入 0.8.15）

前輪依使用者指示暫存原始碼；後續使用者已授權編譯、打包並推送，這批修改納入 0.8.15。實際發行驗證以 [0.8.15 驗收](VALIDATION_0_8_15.md) 為準。

## 行為

- 主畫面提供獨立「登入」按鈕及「尚未登入時無法使用其他功能」提示；成功登入後整區隱藏。設定內移除重複登入按鈕，保留登出。登入進行中仍可取消或重開登入頁。
- 未登入時停用其他按鈕、輸入欄位、連結及設定，包含後續動態產生的控制項；原生層亦拒絕非登入命令。既有有效保存授權可直接使用。
- 登出／到期停止 VNC 同步、選字快捷鍵及浮動圖示，清除前端同步輸入；舊擷取結果不能寫入再次登入後的草稿。
- 設定、確認、改名、VNC 機台管理、必要更新提示這五種 HTML dialog 共用外部點擊關閉；未來新增 HTML dialog 也自動套用。從內容拖到外面、右鍵與取消的指標操作不誤關閉。
- 外部關閉確認視窗不執行待確認動作；改名與機台編輯不自動儲存。必要更新提示關閉後不因狀態推播反覆彈出，但原生最低版本限制仍有效，可回設定下載更新。Windows 原生檔案選擇器與系統訊息框不屬於 HTML dialog。

## 檢查界線

原始碼暫存階段已執行 JavaScript 語法檢查、`node scripts/Test-UiAuth.cjs` 的模擬 DOM 回歸檢查、Rust 格式檢查及 Git 空白檢查。模擬 DOM 涵蓋登入狀態切換、動態控制項鎖定、命令過濾、五種現有及未來新增 dialog 的外部點擊。

原生命令權限單元測試與 WebView2 自我檢查隨 0.8.15 編譯流程執行；完整結果見發行驗收。真實公司瀏覽器授權、Outlook 與 VNC 機台連線仍需公司實機驗證。
