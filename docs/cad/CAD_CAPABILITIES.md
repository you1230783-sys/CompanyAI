# CAD 指令與圖元能力（0.8.72）

工具採固定 JSON 操作；這份表不代表開放任意 CAD 命令列或 COM 方法。

| 類別 | 能力 | 主要範圍 |
|---|---|---|
| 新建幾何 | line、circle、arc、polyline | 原生線／圓／弧、由直線段組成的輕量多段線 |
| 公式曲線 | curve | 有界取樣直線近似，非原生 spline，沒有自動誤差保證 |
| 文字 | TEXT、MTEXT、帶箭頭引線 | 繁體中文；2008須通過字碼頁前置檢查，字形與排版仍須目視 |
| 尺寸 | 對齊、直徑、半徑、角度 | 原生尺寸；角度限小於180度的小角，標註字高／箭頭3 mm |
| 圖層 | 新圖層、顏色／線型、圖元歸屬 | 不覆寫、刪除、更名或解鎖使用者既有圖層 |
| 圖塊 | 基本定義與重複插入 | 本輪定義的線／圓／弧／直線多段線；不巢狀、不載入外部DWG |
| 外觀 | ACI、標準原生線型與圖元比例 | CONTINUOUS、DASHED、HIDDEN、CENTER、DASHDOT、DOT、BYLAYER、BYBLOCK；不改全圖LTSCALE |
| 剖面 | ANSI31 | 有界外框及圓孔，需另核對實際外觀 |
| 既有幾何 | 複製、旋轉、鏡射、矩形陣列 | WCS Z=0的線／圓／弧／直線輕量多段線；依allowed_edits |
| 偏移 | 線、圓 | 保留原物，新增副本；線正距離為起點往終點左側，圓正距離向外 |
| 修剪／延伸 | 兩條直線 | 指定真正邊界及選取端點，有唯一交點；不猜目標 |
| 圓角 | 兩條直線與正半徑 | 指定各自保留側，裁短兩線並新增相切原生圓弧；過大／平行／歧義寫入前拒絕 |
| 固定指令 | ZOOM E／A、REGEN、PURGE、AUDIT N | AUDIT只檢查不修復；不接受任意SendCommand／LISP／Shell／程式載入 |
| 交付 | 分段計畫、新DWG、存檔重開 | 每段1–20項、整圖最多40段／400項／500KB；commit才操作CAD |

## 既有圖面

目前圖面：完整快照／目標詳讀／revision／用戶確認，再修改；**不儲存、不關閉**。磁碟 DWG：在受控新副本上修改，存檔重開核對，原檔不動。主目標及修剪／圓角第二目標都須先讀詳細資料。

2008／2022 的新幾何修改使用固定原生模板與 Undo 群組，完整核對全部可讀屬性及未指定圖元。TrueColor、反應器、擴充字典、傾斜／3D或無法完整核對的目標不開放此組修改。

改字、半徑、字高、移動、顏色、線型、刪除等舊操作仍依版本及 `allowed_edits`。2008目前圖面保留半徑／ACI／TEXT／MTEXT與平面直徑標註的原生備援；副本／陣列／偏移／圓角可透過新幾何工具新增，但 `operations` 通用新增及刪除仍未開放。新幾何批次與改字／半徑等舊批次分開。

改圓不會自動同步尺寸、備註或引線文字；需要依要求逐一更新。2008直徑尺寸安全替換會回傳舊→新Handle，後續須用新Handle。資料核對通過仍不代表設計、字型、排版、製造或裝配審查通過。

## 程式維護

- 新圖固定幾何：`src/cad_geometry.py`；既有幾何計算及原生模板：`src/cad_geometry_edit.py`。
- Schema只擴充4個CAD操作入口，不改Office操作型別。Rust Broker在桌面確認前核對主／副目標詳讀授權，原生端再核對文件、舊幾何與圖層鎖。
- 新增／副本使用明確新檔；回條、程序或屬性核對失敗保留診斷，不自動重畫、撤銷或重送部分操作。
- 模型方法見 `src/projects/skills/cad-advanced.md`；本版驗證與限制以發行驗證文件為準。
