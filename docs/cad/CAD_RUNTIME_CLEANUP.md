# CAD安裝環境與舊版清理（0.8.79）

`C:\largan\LM_AI\cad-<16位內容指紋>`是安裝包自帶的CAD專用Python、COM套件與固定工作程式，不是AI每次任務寫出的腳本。目前EXE依編入的指紋讀取對應目錄，不能在任務結束時刪除目前環境。

過去每個CAD環境改版都建立獨立目錄，以便更新失敗回復及避免覆寫使用中的檔案；成功後沒有清理舊目錄，因而累積。這次在安裝成功後、重新啟動前加入清理，並保留原有交易及回復順序。

## 清理條件

- 目前EXE對應的CAD環境先完整驗證，且永遠排除目前指紋目錄。
- 舊目錄必須為安裝目錄的直接子目錄，名稱符合cad-加16位十六進位，manifest的完整SHA256屬於已知發行名單，且前綴與目錄一致。
- 既有清單由實際Git提交核對，僅保存19個指紋；不重新放回舊版程式碼或驗證歷程。CAD環境更新後先執行tools/update_cad_runtime_history.py，再封裝。
- 先取得整棵候選樹的handle並核對存在的檔案雜湊；占用、硬連結、Junction／符號連結、唯讀、額外或修改項目一律保留，不先刪部分檔案。
- 刪除針對固定handle，不跟隨重新指定的路徑，不使用萬用字元遞迴刪除。manifest最後刪除，允許上次中斷後清理剩餘的已知檔案。
- 清理不成功只記錄在安裝明細，保留其餘目錄並在下次更新重試，不取消已成功的新版本。不處理一般python環境、使用者原件、CAD圖面、對話或專案成果。

原生入口--cleanup-old-cad-runtimes只從自身EXE位置推導安裝路徑，不接受外部清理位置；不啟動CAD或公司連線。回傳0為完成、2為有保留項目、1為無法開始核對。

## 0.8.79驗證結果

已以v142 x64與空Cargo快取frozen編譯，fmt／Clippy及471項Rust測試通過。清理的7項單元案例包含目前版保留、已知舊版刪除、未知／修改／額外內容保留、檔案占用、硬連結、Junction、中斷重試及已載入DLL的image映射。

一般READ／DELETE檔案handle不足以偵測已載入且關閉了loader檔案handle的DLL；檔案預檢另外要求可寫入存取，但不實際寫入，讓Windows拒絕仍被載入的image，避免先刪除其他檔案後才失敗。測試載入獨立的系統DLL副本核對，未修改Windows原檔。
