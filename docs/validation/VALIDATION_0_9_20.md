## 驗證環境差異

- 初次受限 Windows 測試有兩個封存案例在原子替換時收到 Win32 `ERROR_ACCESS_DENIED`。改以正常本機權限驗證後，含既有案例及三種 Excel 結果格式相容的 workspace 測試全部通過。
- 本機 HTTP 案例的中途 panic 為故障注入，專門驗證重開後只查回或續接原請求。
- 介面倒數最初以 1.2 秒的固定時間斷言，瀏覽器計時器與秒數取整可能仍在同一秒。改成等待該文字節點實際變動，重跑通過。
