# 0.9.21 HTTPS v2 驗證紀錄

本版是測試公鑰開發階段。公司 HTTPS 正式與備用 SPKI 保留佔位值。正式路由休眠時，登入與更新沿用既有 HTTP v1。測試公鑰只由本機 fixture 產生，伺服器只綁定 loopback。

## 登入及安全界線

- 驗證 `WinHttpSendRequest` 前的 SPKI SHA-256 檢查涵蓋一般 API、附件、更新、通知 WebSocket 與 PDF 的 WinHTTP 路徑。只略過未知 CA，仍檢查主機名和其他憑證規則。
- Device Grant 在瀏覽器授權完成前未提供帳號代號。防降級狀態保存在目前 Windows 設定檔的獨立 DPAPI 記錄。此設定檔曾建立 v2 時，後續登入仍強制嘗試 v2，即使使用者打算在瀏覽器選擇另一帳號。這也涵蓋登出、過期及重開程式。
- 只在尚未建立 v2 的設定檔接受首次連線拒絕、逾時或已釘選伺服器明確拒絕 v2 的相容流程。收到拒絕後重新取得 v1 登入碼。v2 裝置碼不轉送 HTTP。
- 本機曾觀察 WinHTTP 在分塊上傳時再次執行資訊回呼。釘選狀態現在跟隨整個請求 handle，由其擁有者關閉後再釋放。初次整合測試的 `WinHttpWriteData` 12017 保留於本機驗證日誌。
