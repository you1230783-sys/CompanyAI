# 0.9.23 私聊基礎驗證

私聊入口需要已建立的公司 HTTPS v2、伺服器私聊權限、額外功能與已啟用裝置。正式公鑰為佔位值時入口休眠；本次以兩組即時產生的測試公鑰及 loopback 伺服器驗證 API。

## 本機保存與上鎖

- 使用 Windows CNG AES-256-GCM，對 DEK 與各個資料用途分別使用隨機 nonce 和帳號範圍的 AAD。密碼先經 PBKDF2-SHA256 600,000 次，再與伺服器秘密用 HKDF-SHA256 推導 KEK。現有離線供應鏈未包含 Argon2id，採手冊允許的 CNG 方案，未新增套件。
- 包覆後的 DEK 另以目前 Windows 使用者的 DPAPI 保存，好友、邀請及黑名單檔以 DEK 加密。密碼變更只重新包覆 DEK。伺服器重設秘密後才移除本機金鑰與資料；本機抹除不變更伺服器好友關係。
- 黑名單用伺服器回傳的工號辨識同一帳號，因好友邀請契約提供工號與暱稱。鎖定後好友內容清除，解鎖後同步才處理受封鎖的邀請。
- 正常離開、登出、帳號更換、到期、權限移除與裝置替換會清除記憶體資料及 DPAPI 快取。快取供意外結束後的同帳號恢復，須通過裝置確認、期限與原包覆金鑰一致性檢查，最長 24 小時。Windows 上鎖事件預設啟用。現場 Windows 登出／鎖定事件與公司端權限變更仍待實機驗收。

## 驗證結果

- 本機 TLS 使用實際 WinHTTP 請求驗證 Authorization 與 `X-LMAI-Device`、啟用、搜尋、邀請、接受、拒絕、黑名單自動拒絕、解除好友、重新產生 ID、秘密版本重設及裝置替換。
- Rust 驗證 CNG 來源／密文／標籤驗證、密碼大小寫及字元界線、不同帳號／不同秘密及已重設秘密不能解鎖、變更密碼後原資料密文不變、找不到明文測試文字及暱稱、清除金鑰、可控時鐘與快取到期。
- Edge 測試私聊入口門檻、密碼即時提示、送出後清空、搜尋與確認分離、黑名單及上鎖清除畫面。好友暱稱以純文字呈現。
- MSVC v142 離線 frozen、Clippy 與完整單執行緒 workspace 通過，598 項 Rust 測試。兩項獨立 TLS fixture 分別通過。第一次平行回歸有一項 Windows 共用目錄鎖衝突，另更新設定允許欄位的測試數量與新預設斷言後重跑。

依使用者指示，本階段交付原始碼。正式公鑰與公司端驗收另行處理。
