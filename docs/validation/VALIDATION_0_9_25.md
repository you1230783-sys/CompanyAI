### H1 範圍與手冊差異

`transport-v2.dpapi` 仍是 Windows 設定檔層級，而非手冊寫的每帳號一份。device 授權前沒有帳號身分，這項較廣的「連不上時禁止回退」限制保留並在此明列差異；它不再阻擋可信的 test_accounts／off 回應。不是宣稱已改成帳號級紀錄。公司實測需涵蓋同一 Windows 設定檔先測試帳號、再非測試帳號登入。

### C1 退出與復原驗收

解鎖快取最長 24 小時且不超過自動上鎖期限。選單／托盤離開、更新重啟與 Windows 登出／關機撤銷快取；X 縮托盤保留。登出、換帳號、device_replaced、服務不可用及 Windows 鎖定畫面的既有上鎖規則不變。

- vault 單元測試：真 DPAPI 快取正常退出刪除、意外結束時期限內復原、期限與 24 小時界線、Windows 獨占檔案造成刪除失敗、旗標拒絕復原及解除占用後清理。
- 原生 `--self-check`：合成無金鑰快取經實際 SendMessageW 測試 WM_CLOSE(0)、WM_QUERYENDSESSION、WM_ENDSESSION(FALSE／TRUE)、WM_CLOSE(1)。完整退出與縮托盤使用正式視窗程序。
- **Windows 實際登出／關機事件：待實機驗收**。更新安裝程式重新啟動及公司帳號完整操作仍待實機；本輪驗證它們共用的 WM_CLOSE(1) 路徑，不宣稱執行過新版安裝包。
- 當機復原由 vault 的真 DPAPI 檔案與注入時間驗證；正式介面解鎖後用工作管理員終止、再啟動的端到端操作，留待正式公鑰及公司帳號可用時驗收。

### D03 驗收解釋

D03 沒有 AI 連線步驟，R1 等待表、50 次上限與晚間批次建議不適用。手冊驗收第 7 項以「選項已保存、執行時防睡眠」驗證；手冊原文不修改。Grant.continuous_retry 舊資料預設 false，變更會改變授權 revision；前端變更須重新預覽／授權。執行器原有 RAII 防睡眠保持現狀，結束、失敗、停止時恢復；步驟失敗仍 Blocked、不重播。公司電源政策是否覆蓋防睡眠需公司實機確認。

選項保存／重開與舊資料預設由 Rust 測試驗證；固定流程 native smoke 使用 continuous_retry=true 執行成功、停止續接與失敗邊界。防睡眠 guard 的建立／釋放路徑經來源核對，未修改執行器。嘗試以 `powercfg /requests` 讀取實際系統請求時，Windows 回報需要系統管理員提升權限；因此 **OS 防睡眠請求與公司電源政策效果仍待實機驗收**，不把執行成功宣稱為系統已阻止睡眠。

1. Edge 在受限沙箱連接 loopback 時回報 EACCES；允許本機連線後重跑通過。最初完整 workspace 測試也停在本機連線案例，已核對 PID 後終止該測試樹，改跑完整 library 測試；不宣稱該次 workspace 執行完成。

3. 初次建置提示只供測試使用的 next_ready 包裝函式未使用，已加 cfg(test)，後續 Clippy 通過。其餘增量快取 hard-link 警告如上保留。
