## 新功能核對

- 桌寵六種狀態、貓／狗基本款、PNG 匯入與還原，提供角色名稱置前的 AI 生成提示。GUI 實際將 718,969 bytes 透明 PNG 壓縮至 13,352 bytes、256×256，保留透明與半透明像素，原檔雜湊不變。Win32 視窗顯示／隱藏、通知到期及設定重開由原生測試核對；通知點擊導向與拖曳仍須公司環境人工試用。
- 78 張 Rider–Waite 牌面加使用者牌背均為 360×600，合計 6,525,613 bytes，單張最大 106,301 bytes。檔名對應、來源 Git blob、輸出雜湊及 78 組不同的正逆位牌義已核對。來源固定版本及授權保存在 assets/licenses/tarot-rider-waite。真實 WebView 已看見深藍金色牌背及錢幣國王牌面，中文牌名、方向與解讀位於圖片下方。
- 17 項塔羅／桌寵前端回歸包含 78 張牌、選牌不重複、正逆位呈現、AI 解析問題與確切牌面、PNG 提示與角色提示詞。55 項既有互動教學通過。
- Office 原生測試通過多段 Word、表格追加、Excel 追加、自訂公式及錯誤讀回、PPT 範本複製與保存重開；動態 Formula2 和錯誤批次不部分提交亦已通過最終回歸。
- CAD 原生雙版測試核對共享圓圖塊半徑／顏色、其他圖元保留、一次 Undo、存檔重開及未完整納入共享引用時拒絕；不支援動態、外部參考、巢狀或非均勻縮放圖塊的這類修改。
