# 0.8.79 必要驗證與交付

本版依使用者要求，實作後進版、僅做必要驗證並打包；不重跑完整公司模型、Office、SMB、VNC或CAD圖面操作。

## 完成項目

- 桌寵通知沿用一般設定的字型、字級與介面比例；三款內建TTF以程序私有方式登記，不要求使用者另外安裝字型。
- 角色生成與其他對話框文字欄位加強邊框、內距、編輯尺寸與焦點提示。
- 進階功能新增本機單次提醒，可新增／編輯／刪除，選桌寵或Windows通知；DPAPI保存，最多200項。
- 安裝成功後清理已知且未修改、未占用的舊CAD環境，保留目前環境、未知檔案與使用者資料。

## 實際核對

- MSVC v142 14.29.30133、實際_MSC_FULL_VER=192930159 x64，Cargo.lock／vendor／.cargo/config.toml及空Cargo快取frozen建置。
- fmt、全target Clippy、471項Rust測試通過。新增案例涵蓋提醒到期排序與保存後不重播、加密、輸入／容量／損毀、Windows Shell接收、GDI字型、清理占用／硬連結／Junction與中斷重試。
- 44項桌寵／塔羅／提醒UI互動，57項離線教學、20項對話框登入門檻通過；寬窄畫面及文字欄位已查看。原生WebView2基本自檢及內嵌介面與最終來源比對通過。
- NSIS安裝、更新、PID交接、重啟、失敗回復、修復與解除安裝通過。以Git實際舊manifest重建CAD環境，確認失敗更新保留、占用時整份保留、成功更新後刪除；未知目錄保留。
- R1在封裝前停止以納入最後文字框樣式；R2後的已載入DLL反例發現保護缺口，補上寫入存取鎖定並以R3重建。最終交付只採用R3成功結果。

提醒需要程式持續執行，縮到托盤仍有效；完全退出時不會喚醒Windows，下次啟動依序補送到期項目。Windows通知／勿擾設定可能影響顯示，Shell接受通知不等於使用者已看到。桌寵0秒或全透明改用Windows；編輯已提醒項目需指定未來時間。
