## 本版範圍與實作界線

| 計畫 | 實作與保護 |
| --- | --- |
| F01 匯出 | 選定回答或整段對話由原生歷史產生Word／PDF；不請AI改寫。預覽內容範圍、目的地及省略項，確認一次後保存新副本。預覽綁定帳號、對話版本與資料夾身分；取消或內容變更不能沿用。 |
| F02 新文件翻譯 | 原生`document_task`保存逐段來源、譯文、名詞表與修訂碼；批次原子核對、漏譯阻擋、原檔SHA256保護及中斷續接。新Word保留段落順序，不重建原表格／頁面版型。 |
| F03 文件比較 | Word按正文／表格段落序號；Excel按工作表名稱與座標，或指定唯一鍵欄。公式文字、計算值、顯示值、錯誤及格式分開比較，附原位置與來源版本。 |
| F04 流程提醒 | 已保存流程可設一次、固定24小時或7天提醒；保存帳號、專案、資料夾與範本版本，不保存執行授權。到期只提醒，使用者載入參數草稿並自行送出。 |
| F05 預設工作區 | 首次使用才建立「我的工作區」。拖入檔案先選公司網站附件或本機副本；本機分塊暫存加密、檢查名稱／大小／目錄身分，另建匯入資料夾，讀回位元組後只填草稿。 |
| F06 原樣式副本翻譯 | DOCX依原生字元格式區段翻譯；在副本反向套用並核對文字／字型／段落格式。來源唯讀，圖片及頁首等非翻譯區域保留；禁止模型直接呼叫內部格式操作。 |
| F07 新Markdown | 可建立真正`.md`工作副本，沿用編輯、修訂、另存及讀回流程。既有受保護資料不可匯出Markdown的限制保留。 |

文件工具與快捷入口都要求使用者送出草稿；文件文字、名詞表及匯入檔案不新增權限。成功保存的翻譯輸出保留結果，重試不再發布第二份。發布結果不明時保留副本與路徑，不自動重播。

## 開發中發現並修正

1. 新工具JSON schema漏列共同`progress_note`要求；補齊schema與工具目錄案例後，全庫測試通過。
2. Word COM物件若以尾端暫時值建立，可能在Apartment釋放後才關閉文件；改成明確的Session區域變數，讓文件先關閉。曾留下三個本輪唯讀測試文件；確認ROT完整路徑、Saved、ReadOnly及文件數後，以COM關閉自己的測試文件，未強制終止使用者Office程序。
3. 混合字型的`Font.Name`會隨中英文字串改變，不能當作跨語言字型身分；改核對Ascii／FarEast／Other／Bi字型與其他格式。保留`Font.Duplicate`，不重新套用會清掉直接格式的Style。測試要求最後保存重開後格式仍一致。
4. 圖片錨點的文字偏移會隨譯文長度改變；核對圖片／表格屬性與格式，沒有把應該改變的文字位置誤當成圖片損壞。
5. 匯出暫存目錄使用一般目錄鎖，阻止Word另存操作；改用既有Office副本流程的暫存鎖，仍保留輸出目錄與來源鎖定。
6. 新附件目的地選擇後，數量超限的提前返回沒有立刻解鎖介面；恢復控制項後才檢查網站附件限制，原生自檢同步選擇明確目的地。
7. Excel計算值快照原本就是字串，定向測試卻以JSON數字讀取；修正測試契約後，真Excel公式／計算值驗證通過，未放寬正式比對。

另保留測試啟動失敗：早期使用相對根目錄，被既有絕對路徑檢查拒絕；一次受限執行環境無法建立AppContainer（0x80070005），在授權的原生測試環境重跑。Clippy曾指出測試模組後仍有正式項目，已調整項目順序。這些失敗都不列為PASS。完整回歸另刻意注入panic以測試checkpoint恢復，須後續恢復案例通過才算成功。

## 限制與公司待驗

- 翻譯的模型品質、公司專有名詞、真公司附件服務與加密Office仍須公司實測。本機用固定譯文核對執行與來源保護，不能代表翻譯語意正確。
- 原樣式翻譯只處理DOCX可安全分段的正文／表格文字；頁首頁尾、文字方塊、註解與特殊欄位不翻譯。文字長短可能影響換行、表格高度及分頁；混合字型分段也可能影響語句自然度，交付需人工審閱。
- 匯出提供基本標題、段落、表格、程式碼及專案內獨立PNG；不是完整HTML／Markdown渲染器。連結以原文字保留，遠端圖片不下載，非PNG、附件、互動圖表或不完整回答會列警語。
- Word比較是位置對應，插入段落可能使後續位置偏移。Excel唯一鍵模式要求第一列標題、非空且不重複的鍵；差異最多200項／48KB，會明示截斷與總數，不假稱未列出者相同。
- 流程提醒需應用程式開啟；關閉／睡眠期間不執行，恢復後合併過期提醒。24小時／7天是固定間隔，跨時區或夏令時間須重新確認提醒時間；未建立無人值守排程。
- 真Classic Outlook信箱、公司SMB／VNC、防毒、多螢幕框選／DPI及桌寵人工操作，延續前版未驗證範圍。
