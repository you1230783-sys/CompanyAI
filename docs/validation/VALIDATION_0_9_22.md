# 0.9.22 通知設定驗證

## 彈出通知盤點

| 分類 | 原生來源 | 遷移前的方式 |
| --- | --- | --- |
| AI 回覆完成 | `src/ui/work.rs` 的一般工作終態 | 桌寵 |
| 專案任務結果 | `src/ui/projects/attention.rs` 的完成、失敗及可恢復暫停 | 桌寵 |
| 專案等待使用者確認 | `src/ui/projects/attention.rs` 的問題、CAD／檔案／Outlook／圖表確認及等待結果 | 桌寵，執行中等待另有工作列閃爍 |
| 本機提醒 | `src/ui/reminders.rs` 的一次、重複及流程提醒 | 每則各自選擇桌寵或 Windows |
| 流程排程結果 | `src/ui/schedules.rs` 的完成或異常結果 | 桌寵及 Windows |
| 晚間批次結果 | `src/ui/projects/batch.rs` 的晨間摘要 | 桌寵 |
| AI 服務通知 | `src/ui/events.rs` 的背景通知收件匣 | 桌寵 |
| 網站全站通知 | `src/ui/site.rs` 的背景全站鈴鐺 | 桌寵 |
| 縮到系統托盤的提示 | `src/ui/window_behavior.rs` 的托盤提示 | 桌寵 |

通知中心、排程審計、提醒及批次資料依各自規則保存。桌寵泡泡樣式、顯示時間及手動預覽仍在原設定處。私聊通知待後續版本加入。

舊設定檔先以「沿用舊設定」載入。先前的彈出總開關不控制提醒、托盤提示及等待確認的工作列閃爍，移轉保留這些差異。使用者可逐項覆寫；新設定檔預設 Windows。選擇桌寵後，若額外功能關閉或改用無桌寵成品，暫用 Windows 並保留桌寵偏好。

## 驗證範圍

- Edge 實頁覆蓋分頁順序、鍵盤選取、九項原生命令、關閉全部、舊設定載入、兩種桌寵門檻及 520 px 版面。舊設定分頁、58 題教學、排程及桌寵頁面一併回歸。
- 六組 Edge 測試通過。一次瀏覽器初始化提前結束，重啟隔離測試設定檔後通過。
- MSVC v142 離線 frozen，593 項 Rust 測試通過。涵蓋遷移、各分類、全部關閉、桌寵不可用的備援、Windows 托盤通知提交及 UTF-16 截斷。前版的獨立 TLS fixture 仍由專用腳本執行。Clippy 與無預設 features 的編譯檢查通過。
- 原生 WebView2 自檢六份收據通過，其中專案 composer 20 案包含關閉彈出後仍保存通知，以及點通知返回可恢復的專案。Windows 是否實際顯示提示仍由使用者系統的通知設定與勿擾狀態決定。
- 本版依測試公鑰階段的發佈界線交付 Git 原始碼。
