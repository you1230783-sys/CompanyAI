# 分版實作與驗收計畫

更新日期：2026-11-04。狀態使用「待實作／實作中／待驗證／已驗證／已發行」。程式已修改不等於完成驗證，缺少公司環境的項目必須列為未驗證。

## 不變條件（每版交付逐項核對）

- [x] 安裝路徑固定 `C:\largan\LM_AI`，配合公司防毒白名單。
- [x] 公司服務維持既有 HTTP 與 lm_server；本批不切換 HTTPS。
- [x] `machines.json` 格式、明文保存及 JSON 匯入／匯出不變，不收入診斷包。
- [x] 程式內更新維持公司伺服器下載、RSA 簽章、SHA256 與同源檢查，不允許 GitHub 替代更新來源。
- [x] 原文件預設唯讀；CAD 測試用新圖／副本，作用中文件修改仍須原有明確確認。
- [x] 不重播已成功的寫入；未知結果先核對，失效授權不從歷史或摘要恢復。
- [x] 私鑰、Token、個人設定、對話、機台資料與本機驗證私有輸入不提交。
- [x] Windows 11 x64、MSVC v142；以實際 cl/link 及空 Cargo 快取 frozen 建置驗證。
