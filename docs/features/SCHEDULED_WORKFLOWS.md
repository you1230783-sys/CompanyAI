# 程式開啟期間的固定流程排程（0.9.11）

本功能只在 LM_AI 開啟或縮到托盤、登入有效、版本允許且沒有其他工作時執行。不是 Windows 排程服務；退出程式後不會啟動程序。固定流程直接使用原生 Broker，不請模型修改步驟、程式碼或參數。

## 設定與操作

1. 在專案成果中心選擇已保存的流程，填寫本次參數，按「設定排程」。
2. 選擇未來時間及單次／每24小時／每7天。這是固定間隔，不是工作日或夏令時間日曆。
3. 按預覽，核對帳號、專案根目錄、來源、參數、完整步驟及程式碼，再按「確認授權並保存排程」。步驟間的結果引用仍顯示引用式，執行時只可讀前面實際成功的結果。
4. 「設定＞進階功能＞流程排程與執行審計」可查看下次時間、停止、停用、執行結果及成果位置。此入口與額外功能／VNC開關獨立。

預覽有效2分鐘，修改時間需重新預覽；確認只接受原生產生的一次性ID。確認時重查帳號、原對話、專案根目錄檔案身分及範本版本，不能由前端直接提交授權內容。

到期時忙碌最多延後5分鐘；超過5分鐘不補跑寫入，重複排程前進至未來時間，單次排程結束。程式關閉或休眠也適用此規則；重新開啟落在5分鐘寬限內時仍可能執行。來源、輸出名稱及固定參數不會自動換成當日值，需要變更請重新預覽建立排程。

## 執行與恢復邊界

- Store先持久認領execution ID，成功後才啟動執行緒；一次只跑一項排程。執行時保留使用者草稿，但拒絕另一個專案工作或模型補充，避免固定流程忽略新要求。可停止、登出或離開。
- 每次啟動／續接重新核對授權身分，每一步核對專案根目錄及範本。各工具仍檢查來源、版本、受控副本與路徑；不增加任意檔案或命令入口。
- 只載入已核准步驟所需的既有內建技能。沒有模型、互動同意或品質選擇器；需要這些互動或沒有可用渲染器的工具可能暫停／失敗，不自動擴大權限，也不宣稱所有保存範本皆可無人值守完成。
- 每步先保存 `InFlight`，再經原有工作流程工具執行；成功後保存完整 Broker 快照及下一步位置。操作ID沿用 `workflow:{execution_id}:{index}` 的既有摘要規則。
- 已保存 `Ready` 表示下一步尚未送出，可由使用者核對後續接；沿用原副本、版本與已完成結果。登出或取消可能讓正在執行的操作停在未知狀態，不能保證撤銷已寫內容。
- `InFlight`、失敗、缺少或無法讀取的紀錄不提供自動重播。重新啟動只核對紀錄，絕不自動續跑未完成execution。即使寫入已成功但成功快照尚未保存，也保守視為未知。
- 同一execution初始紀錄採 `create_new`，已完成的ID也不能覆寫重跑。全部完成，或確認尚未派送任何步驟的 `Skipped`，才前進到下次；執行中失敗／結果未知仍停用，避免再次寫入。
- Office流程派送前檢查已開啟的Word／Excel文件與PowerPoint實例。確認占用時只略過當次、留下零步驟審計，重複排程保留下次；不關閉使用者文件。若Office在預檢後才被開啟而步驟失敗，仍按未知結果保守停用，不自動重播。
- 完成、略過、失敗及停用使用桌寵／Windows通知，點擊直接開啟目前帳號的審計。遵循通知開關與Windows勿擾設定；關閉通知仍保存紀錄。忙碌／未登入超過寬限也有未派送審計。

## 保存與審計

`workflow-schedules.dpapi` 保存核准範本／固定參數、排程與審計摘要；`workflow-executions/<execution>.dpapi` 保存持久階段、成功步數、完整Broker操作結果及成果位置。都使用既有Windows使用者DPAPI及原子替換。首次execution使用不覆寫建立，建立未完成也不啟動步驟。

原生介面只顯示目前登入帳號的參數及審計。停止入口可在登入失效後使用；新建／續接仍需有效登入與版本。日誌包含私有來源與參數，不提交Git、不放公開驗證報告。

上限50項排程、100次執行審計；達上限停止新增執行並保留紀錄，由維護者另行封存，不自動刪除審計或成果。已交付副本仍需使用者核對，不代表內容或公司流程已批准。

## 驗證方法與待驗狀態

單元案例涵蓋認領去重、到期寬限、重複排程、持久續接身分、損毀保存及未知狀態。`examples/schedule_smoke.rs` 使用當次正式EXE與真正Broker／Worker：保存副本、成功ID拒絕重播、安全邊界續接，以及送出前／實際保存後但成功快照前中斷。`scripts/Test-Schedules.cjs` 測預覽與確認、過期回覆、時間修改、停止、未知結果及版面。

實際結果以 [0.9.11驗證紀錄](../validation/VALIDATION_0_9_11.md) 為準。本說明是實作契約，不能單憑文件視為PASS。公司帳號、模型、加密Office、公司網路、睡眠／鎖屏長時間排程仍需公司實機驗收。
