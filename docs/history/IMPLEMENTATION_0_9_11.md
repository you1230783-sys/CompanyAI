- `read_file`與`read_code_section`回傳解碼後文字的SHA-256，`run_python`則核對原始位元組SHA-256。UTF-8 BOM等編碼差異會使未變更的檔案被誤判；現有revision測試僅涵蓋無BOM的UTF-8。公司來源是否帶BOM尚未確認，不能把模型推測的路徑大小寫當作已確認根因。
