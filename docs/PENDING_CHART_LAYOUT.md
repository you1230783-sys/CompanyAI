# 前置設計：參考線文字排版與預設配色

> 已併入0.8.48，並新增圖中文字與AI編輯。以下保留前置階段的行為與未編譯紀錄；目前功能、資料傳遞及完整驗證以 [0.8.48](VALIDATION_0_8_48.md) 為準。

當時依使用者要求只修改原始碼與文件，沒有編譯、進版、製作安裝包或推送。正式 EXE／NSIS、更新清單與發行驗證仍維持0.8.47。

## 使用方式

### 參考線標籤

- 垂直／水平參考線仍畫在原本數值位置；文字改用獨立文字框，必要時加引線。
- 自動排版會換行，避開其他參考線文字、主標題與圖例。空白標籤仍只畫線；縮放範圍外的線及文字一起隱藏，還原範圍後再顯示。
- 若十條長標籤在小圖框內無法全部避開，保留文字並提示「請放大圖表或縮短標籤」，不假裝已排好或默默省略。
- 自動避讓針對文字框；不保證同時避開所有資料點。使用者可以用下方模式將文字移到空白處。

### 調整排版

1. 在完成的圖表按「調整排版」。只有此時才顯示可拖曳的框線，平常保留圖例切換、提示與縮放。
2. 拖曳主標題、圖例或參考線文字。也可聚焦框線後按方向鍵微調，Shift＋方向鍵每次移10像素。文字移動不改變資料點、軸範圍或參考線數值。
3. 按「完成排版」保存；「取消排版」回到本次調整前的位置；「自動排版」只清除位置草稿，保留配色、參考線及其他編輯，仍需按完成保存。

位置以圖框內的比例保存，縮放圖框及1600×1000 PNG匯出均重新計算文字大小與避讓。比例位置是偏好位置，靠近邊界或與其他文字相撞時，顯示位置會往圖框內調整。這次支援主標題、圖例與參考線文字；不提供拖曳資料點、座標軸或任意新增物件。

### 預設顏色

在「設定 → 一般 → 圖表預設顏色」選八個系列色票，再按「儲存配色」。單一系列使用第一色；散佈點、折線、面積及長條依相同系列順序使用色票。

新圖表及未套用自訂設定的舊圖表使用此設定，已顯示的畫布也會刷新。已套用自訂設定的圖表有自己的配色快照，會保留原配色，可在圖表編輯器個別修改。這些顏色也用於新匯出的PNG；已經儲存的檔案不會重寫。「還原預設色票」只改設定草稿，按儲存後生效。

## 保存與維護

- 個人設定新增 `chart_palette`，原生入口只接受八個 `#RRGGBB` 色碼；舊設定或不合法色票回到內建預設。先寫入成功才套用記憶體設定，沿用登入與版本門檻。
- 既有 `charts::Style` 新增預設 `layout`：主標題、圖例及按參考線順序對應的文字位置，座標均為有限的0–1比例。舊圖表沒有此欄位仍可載入。
- 排版沿用既有 `chart_customize` 及加密歷史保存，不新增後端API、不把個人呈現設定傳給模型。刪除參考線時同步移動其位置記錄，改值／換軸後清除該線的舊位置。
- `chart-layout.js` 集中處理文字量測、避讓、畫面／PNG與拖曳框。座標系先完成 `setOption` 才以 `convertToPixel` 取得線的位置，遵循 [ECharts 官方座標換算說明](https://echarts.apache.org/handbook/en/how-to/interaction/drag/)；不修改原始資料陣列。
