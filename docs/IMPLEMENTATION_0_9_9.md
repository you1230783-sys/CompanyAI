# 0.9.9 原始碼交付紀錄

2026-11-05：依使用者最新指示，本版只提交及推送原始碼。**未編譯、未執行驗證、未封裝，不建立 0.9.9 Release。** 程式與新增測試合併至 0.9.10 後再完整驗證。僅執行 `cargo fmt --all` 排版，不視為測試通過；當時可下載且已驗證的安裝包為 0.9.8。下方「待驗」保留來源交付時的狀態；後續合併實測已完成，結果與發布進度見[0.9.10驗證紀錄](VALIDATION_0_9_10.md)。

## F08：Word 內容對齊

- `src/projects/documents/word.rs` 以原文、種類及原生表格範圍作順序 LCS 錨點，最多每份 2000 段、約 400 萬個 u16 格。
- 插入／刪除不再單純依 p1、p2 位置逐一比較。相同原文對齊後再比較完整格式；格式索引先還原實值。
- 前後位置分別列在 `before_location`／`after_location`。重複原文明示歧義；單段間隙只稱候選替換，多段間隙列新增／刪除。移動、表格身分及語意相同都不猜測。
- 表格文字保留文件順序，以原生 `WordInTable` 避免正文與表格同文交叉配對；不宣稱跨表格儲存格身分追蹤。Excel 座標／唯一鍵演算法維持。
- 保留最多 200 筆／48 KB 差異與完整數量、截斷旗標。新增插刪、重複、純格式、表格、空文件及界限案例，均待 0.9.10 執行。

## F09：額外功能偏好

- `extra_features_enabled` 新、舊設定預設 false，與 VNC 獨立，保存／讀回及行為命令皆納入。
- 設定＞進階功能新增「開啟其它額外功能」。關閉時移動同一個 Outlook 按鈕至側欄；開啟後恢復進階功能入口，不複製 ID 或重綁登入行為。
- 桌寵／塔羅入口及教學受額外功能開關控制，VNC 入口／教學受原開關控制，編譯能力仍優先。原生目錄、前端搜尋及直接開啟使用相同範圍。
- 不因關閉額外功能而抹除原桌寵或 VNC 個人偏好。新增四種開關組合、舊設定及直接開啟回歸；既有需要額外功能的案例改為明確啟用，均待執行。

## C01：輸入軟目標與原文保留

- 完整新請求估算超過 50,000 tokens 才整理，目標降至約 40,000；包含動態提示及工具定義，沿用字數 × 0.48 估算與 API usage 分離，沒有改模型技能或筆記內容／保存流程。
- 移除日常最多三組、30 組／156 KB 強制整理、240 KB 投影裁減與匯出成功立即整理；60 工具／80 回覆換批仍保存 checkpoint，但不再因此移出原文。日常也不因較早助理答案達 60 KB 而節錄。
- 整組移出 assistant/tool，依完整連續投影及索引同步 checkpoint，而非可能重複的 tool call ID。移出後下輪不再重新加入，保留 10,000 tokens 緩衝。
- 使用者原文、補充、最新結果，以及程式可核對的未完分頁同版本證據／目前副本同版本證據受保護。沒有狀態能證明仍作用中的其他舊結果按時間優先移出，不宣稱能判斷所有語意引用需求。保護內容超標可維持超過軟目標；服務端大小／訊息能力仍可能使請求暫停。
- 錯誤恢復、主動交接、新補充及明確續接仍沿用各自精簡規則。操作封存、來源版本、未知提交、去重及無進展／失敗計數未放寬。筆記提示本身的既有頻率維持，不再直接觸發日常裁減。
- 新增超過三組保留、50k→40k 緩衝、重複 call ID、動態提示位置、持久續接及證據保護案例；原生長任務改檢查完整請求估算而非舊 byte 門檻。均待 0.9.10 執行。
