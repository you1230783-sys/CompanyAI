# CAD 分頁與上下文整理銜接

本批修改納入 0.8.68；發行建置與驗證狀態以 [VALIDATION_0_8_68.md](VALIDATION_0_8_68.md) 為準。
以下保留修改階段的測試範圍與限制。

使用者觀察目前圖面讀取的 offset 持續在 0／100 循環。
單靠畫面原有「讀取完成」訊息無法區分翻頁與重讀；此次依明確 offset 回報修正進度銜接。

## 修改

- Coverage 獨立保存 CAD 來源、revision、已交付區間；checkpoint 可還原，模型狀態固定帶 cad_paging。
- 每輪提供下一個未讀位置與全部圖元是否已交付；不因精簡歷史丟失閱讀位置。
- 重讀相同來源版本的頁面不算新增閱讀範圍，沿用既有無進展提醒與暫停機制。
- 圖面版本／作用中文件改變時清除該來源的舊範圍，不將新舊資料混用。
- 目前圖面回傳 offset；同文件、同 revision 重讀第 0 頁保留累積 Handle，變更時清除。
- CAD 技能要求每頁整理已核對／待核對項目，完成閱讀後不再翻頁；舊細節從 read_work_log 查回。
- localhost 實測另發現 cad_active_read／cad_active_edit／cad_excel_plan／cad_excel_apply
  缺少 progress_note，和共用交接規則矛盾；補齊四者欄位並以全目錄回歸防止遺漏。
- 已交付圖元不是已完成規格驗證；進度資料不授予寫入權限，原有操作前圖面核對保持有效。

## 限制與驗證

本次沒有改成快取作用中圖面，也沒有提高每頁 100 筆；每頁重新掃描整張圖的成本仍存在。
分頁進度可以協助模型避免循環，但不能保證模型每次遵從提示；既有無進展機制仍是最後保護。
本次新欄位相容舊 checkpoint，但舊任務尚未保存的 CAD 範圍不能憑空補造。

新增 Rust 案例覆蓋 0／100 重讀、checkpoint 恢復、末頁與 revision 變更後範圍重設。
後續使用者授權 localhost Luna 實際測試，已完成 v142 x64／空快取 --frozen 基礎建置，
包含 26 項 progress 測試通過；維持不進版、不封裝推送。
交接筆記補正後的 6 項 agent schema 測試通過；實際模型是否完成核對仍須另看實測紀錄。
本機模型與 CAD 實機紀錄見 VALIDATION_LOCAL_LUNA.md；公司模型尚未驗證。
