# 一般使用者CAD情境實測（2026-10-18）

## 範圍與方法

使用者要求日常模糊需求、多種類型及較大住宅／廠房，時間不趕，逐案保留驗證。依`LOCAL_MODEL_VALIDATION.md`的長期流程，本輪針對CAD做較完整的情境集；不是全應用程式已完成驗收。

案例：浴室雙層置物架、免鑽孔門背掛架、桌下主機收納、陽台花架、兩層住宅、12台小工廠、三種類各20台的大工廠。每案初始只給一般使用者的需求；必要追問才提供預存角色補充，不餵工具參數、座標、正確計畫或Oracle。

案例原文及角色資料在`tools/cad_user_cases.json`。每案2008／2022各一份獨立專案，Strata Q2、128K、none，真實messages／tools經127.0.0.1:8773轉送，保留原始回覆；不由Codex代改模型參數。案例最多兩次角色補充；仍需要其他資料則列待補充，不強迫畫完。

批次入口`examples/cad_model_suite.rs`呼叫正式runner／Broker／CAD worker，沒有桌面確認回呼，因此不能自動同意既有文件寫入、啟動／重連或失敗後重畫。這是命令列原生流程驗證，未涵蓋GUI輸入、按鈕與通知；真正CAD畫面另行核對。
