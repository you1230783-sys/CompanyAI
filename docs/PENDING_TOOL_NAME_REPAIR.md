## 變更

- `reply::parse` 以 ParseOutcome 區分可執行操作與可修正格式錯誤，runner 將原因送入既有 repair 流程。
- `action:"tool"` 缺少 request、request 非物件、缺少 request.tool、tool 為空白或不是字串：不執行任何工具，向模型指出具體錯誤並要求重新提供同一操作的完整 JSON。
- 明確提供非空但不支援的名稱（例如 shell）仍立即停止，不降低工具白名單限制。
- 不依 path／summary 等參數猜測或自動補上工具，不改寫 operation_id、來源 revision 或 note_revision。模型補齊格式後，仍須通過一般工具權限及版本檢查。
- 沿用同一段最多兩次、全任務最多六次修復；已成功的工具不重播。最新技能只教 tool_calls，工具名稱固定在 function.name；request.tool 僅保留舊回覆相容處理。
