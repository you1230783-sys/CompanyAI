0.8.73 修改與驗證清單（2026-10-19，本機驗證與NSIS完成，現場界線見驗證紀錄）

0.8.72 已編譯、打包並推送 main（1b75f636e5591c683017886cd214ea26c18619ca），七組公司測試提示詞在 docs/COMPANY_TEST_PROMPTS_0_8_72.txt。
推送0.8.72後已將以下1–15項加入原始碼。公司端回報主要流程可完成後，使用者已明確授權進版0.8.73、完整建置、Strata測試、NSIS打包及Git推送；先前僅修改來源的階段已結束。本清單保留各項實作範圍，完整結果以docs/VALIDATION_0_8_73.md及offline/feature-verification-0.8.73.json為準；不沿用舊候選或舊版PASS。

1. 新增專案視窗
   縮短敘述，支援檔案類型改為條列或獨立按鈕顯示；調整專案名稱標籤、輸入框及建立專案資料夾按鈕的間距，避免擠在一起。

2. 快速模型送出確認
   一般對話與專案對話在送出前，若選用快速模型，顯示確認框。
   「快速模型使用工具能力較差，回饋品質可能不如預期」以紅色呈現，並說明快速模型建議用於翻譯等快速動作。
   透過快速動作送出時不顯示此提示；確認的是實際本次送出所選模型。
   取消保留草稿／附件；確認後重新比對對話、模型及草稿。手動重試、專案續接與手動送出排程也經過確認；快速動作重試以首次操作紀錄判斷免提醒。

3. 專案資料夾捷徑
   點擊專案上方顯示的資料夾路徑，以 Windows 檔案總管開啟該專案資料夾。

4. VNC 快速連線匯入／匯出
   頁面右上加入匯入／匯出。匯出 JSON 至使用者指定資料夾；匯入使用者提供的 JSON，驗證格式與內容後才儲存到本機。
   匯入可選覆蓋或加入，需明確處理機台名稱重複的情況；驗證失敗不得覆寫既有資料。
   使用原生選檔／資料夾視窗；4MiB、20000台匯入上限，拒絕重複分類鍵及不合規欄位。同分類重名以「（匯入 2）」接續命名，機台判重不分大小寫、分類區分大小寫；加入保留舊機台，覆蓋只取代機台清單，不改Viewer／連線設定。額外欄位與密碼留在原生層，預覽只顯示數量；匯出為含既存密碼的原格式JSON，同名備份加序號，不覆寫舊檔。

5. 介面大小設定
   放在文字大小旁邊，提供類似網頁縮放的整體介面大小設定；停用使用者直接以 Ctrl＋滾輪縮放，統一由設定調整。
   使用WebView2原生縮放，可選75／90／100／110／125／150／175／200%，預設100%，保存後重開沿用；同時關閉瀏覽器縮放快捷鍵與支援環境的觸控縮放。

6. 字體選單與離線字型
   0.8.72 原先指定 Segoe UI、Microsoft JhengHei UI、sans-serif；沒有指定新細明體。
   中文可使用微軟正黑體 UI 備援，實際各字元仍受系統字型備援影響。程式碼區使用 Consolas／Cascadia Code 等等寬字體。
   使用者已選定四項：微軟正黑體、jf 粉圓體、霞鶩文楷繁中非等寬、霞鶩文楷繁中等寬。
   預設為霞鶩文楷繁中非等寬；選項放在一般設定，與介面大小同區域。
   開源字型優先查找本機已安裝檔案，核對官方授權後隨應用程式離線附帶字型與授權；微軟正黑體使用 Windows 系統字型，不將它當作開源字型重新散布。
   已加入本機jf粉圓2.1、霞鶩文楷TC／MonoTC 1.511 Medium的未修改TTF，並與官方固定tag逐檔雜湊核對。ui/fonts/包含完整OFL與相關Apache授權、NOTICE、來源及SHA256清單；一般設定可離線查看授權。Build.ps1已核對字型完整性，避免將LFS指標誤打包成字型；本次完整離線建置及字型載入驗證通過。

7. 檔案清單與一般文字支援
   清單顯示未知或未支援的副檔名，不再因副檔名白名單而隱藏檔案。
   讀取時以實際內容與編碼判斷是否可當一般文字，讓 bat、cmd、ps1 或其他文字檔可沿用文字副本閱讀／編輯；不用逐項開放新副檔名。
   二進位、無法解碼或無法可靠讀取的內容須明確回報實際限制，不以亂碼冒充成功；維持專案授權根範圍、內部／機密資料與既有副本完整性界線，不自動執行來源命令稿。
   清單固定排序、每頁200項，next_offset可繼續列出全部類型；單一資料夾最多100000項。一般程式／未知文字原件上限4MiB；TXT／MD文件沿用200KB，所有一般文字工作副本上限200KB。嚴格UTF-8／BOM、UTF-16 BOM及可無損往返的Big5／系統ANSI讀取，保留來源編碼與BOM；Python kind=text也不再以副檔名白名單擋住未知文字，仍只分析靜態快照，不執行來源。Python的既有編碼／32MiB與隔離限制不變。

8. 同一專案對話共用成果資料夾
   以原生對話ID推導穩定的 _AI_Output/對話_<識別雜湊>/，第一次實際輸出才建立。同一對話的多個任務、後續訊息與程式重開沿用同一位置，不同對話分開；對話標題改名不改變位置。
   Mermaid原始MMD、另存MMD／PNG／SVG與圖形上的手動儲存按鈕共用此位置。一般文字／Office副本、CSV資料集、圖表PNG、Python成果、CAD新圖／修改成果及預覽也沿用；同名檔案以create_new或CAD保留檔加序號，不覆寫舊成果，CAD診斷亦各自保留。
   CAD唯讀工作副本的固定名稱索引仍需隔離，放在共用資料夾內的獨立暫存子目錄，不再散落於 _AI_Output 下多個成果資料夾。新CAD成果使用可與來源唯讀鎖共存的目錄保護及唯一anchor；目錄連結／更名防護保留，相關檔案共用及雙版CAD原生驗證結果見本版驗證紀錄；實際報告儲存修正另見第15項。
   既有輸出不搬移或合併；舊版暫停任務繼續使用已驗證的舊草稿目錄，新任務採用對話共用目錄。本次已完成相關回歸、完整建置及Strata共用目錄核對。

9. CAD批次預檢、失敗狀態與重複查詢
   在複製DWG或要求目前圖面修改確認前，同時檢查主／副目標是否已讀details、同批修改Handle重複、幾何修改混入operations／改字／半徑，以及快照已知的allowed_edits限制。一次回傳全部可判定問題與Handle；PRECHECK_REJECTED明示未啟動CAD修改，不消耗原生寫入次數。原生的完整修改驗證仍保留。
   原生FAILED／UNKNOWN不再因工具程序正常回傳而顯示「完成」；UI與任務狀態使用相同失敗結果，未知結果仍不自動重播。成功副本讀取後固定本任務確切ProgID，新成果latest沿用該版本；明確傳入不同版本先回報，不猜年份後綴或偷偷切換CAD。
   本機快照保存全部已交付候選集合，各輪附種類讀取進度與最多64筆／8000bytes精簡精確幾何；不再只靠舊10筆滑動視窗記得已讀內容。大型幾何整筆省略並標示，不截斷頂點；同版本已在常駐狀態的逐字屬性／幾何從送出歷史投影去重，原始日誌與本機完整資料不改寫。查詢不重送內部native_revision DXF資料。
   同版已讀範圍、連續無新增查詢及最新存檔成果提供明確收尾提示；指南要求必要核對一次、保存結論後交付，不為逐步報告排版反覆查線／圓／弧。已讀不等於使用者規格通過，不強制以讀取數量宣稱驗收成功。cad_query仍直接讀本機索引；沒有改成逐個COM點選，也沒有取消來源變更檢查。本次輪數及token用量記於驗證紀錄；因模型輸出與錯誤不同，不宣稱固定減幅。

11. 資料夾誤用read_file的明確提示與批次列目錄
   公司測試提供的完整工具紀錄確認：四個子目錄被當作read_file檔案開啟，Windows因此回報os error 5；該次失敗不能用來推定HTML不支援或資料夾ACL不足。未另外取得HTML檔案讀取失敗證據。
   一般檔案讀取與批次預檢共用checked_file，資料夾誤用明確提示改用list_files；handle層原有連結／替換／檔案完整性檢查保留。目錄清單附read_tool=list_files；run_batch實際分派與schema開放list_files，可並行列2–4個獨立子目錄，仍由原有list_files執行範圍與排除檢查。Mermaid指南同步指導先列目錄再讀檔案，不自動改工具或隱藏真正的ACL錯誤。

12. 最小化與系統托盤
一般設定新增預設勾選的「縮小時保留在 Windows 工作列」。勾選時縮小保留工作列；取消勾選時縮小收到托盤。按 X 一律收到托盤，提示在托盤圖示按右鍵 → 離開。設定保留，舊偏好預設勾選；草稿與背景工作延續。實際 Windows 是否顯示彈出提示仍依系統通知／勿擾設定。

13. Mermaid 跨輪銜接與行號對照
