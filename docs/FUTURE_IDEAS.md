## F-MCP：以 MCP 接入公司內網服務

- **目的**：日後接公司 ERP、MES、知識庫、工單等系統時，不必每加一個工具就改 EXE、發新版。
- **排期條件**：公司內實際出現需要接入的內網系統，且 0.9.14～0.9.17 的功能已完成實測。
- **必須遵守的安全邊界**：
  1. 只允許管理者設定的白名單伺服器；使用者不能自行新增、修改或匯入伺服器設定。
  2. 只使用 HTTP（Streamable HTTP）型 MCP，連到核准的內網位址。**不支援 stdio 型**，因為它會在本機啟動外部程式，違反「不執行使用者端程式」的原則。
  3. 會修改資料的 MCP 工具預設需要使用者確認；結果納入既有的操作 ID 去重、checkpoint、任務總覽與 Error Code 分類。
  4. LM_AI 的公司登入 Token 不轉交給 MCP 伺服器；各服務的授權另行設計。
  5. MCP 回傳內容視為不可信資料（可能夾帶誘導指令），與文件、郵件內容一樣不能擴大權限。
  6. 白名單、工具清單與 schema 版本應記錄在診斷資料中（只記名稱與版本，不記內容）。
- **待決定**：白名單由網頁端下發或隨安裝包固定、每個工具的確認層級、與公司資料技能（目前由網頁端提供）的分工。

### B：同一張工作表的讀取預算提示

同一工作表累積讀取超過一定量（例如 3 批或 3000 格）時，在工具結果附上提示：「大量資料請用 export_excel_dataset 匯出 CSV，再用 run_python 分析」。只提示，不強制擋下（與 M7 的提示做法相同）。

### C：Excel 索引工具（類似 CAD 索引）

新工具（例如 `index_workbook`）：由 Excel COM 一次將各工作表的使用範圍匯出成本機 CSV（設上限），只回傳每欄概況（表頭、型別分布、空白數、最小值／最大值、前幾個不同值、公式格數）。之後模型以 `run_python(kind=csv)` 查詢。

### 決定依據

- 模型仍逐批讀取 → 先做 B。
