# CAD 本機快照、候選查詢與局部預覽

0.8.68 建立本機索引與候選查詢；0.8.69 整合 CAD 程序內批次匯出，並將相同流程用於修改前、存檔前及重開核對。建置結果、兩版本實測及未驗證範圍見 [0.8.69 驗證](VALIDATION_0_8_69.md)。

0.8.68 的 Luna low 實測曾遇到 2008 大圖逾時及模型錯誤編輯參數，原始結果保留於 [Luna CAD 專項實測](VALIDATION_LUNA_CAD_INDEX.md)。不能把新版本的讀取效能改善視為所有模型均可正確修改的保證。

## 工作流程

1. `cad_snapshot(version, path, refresh)`：path=null 讀目前圖面；專案相對 DWG 路徑則沿用唯讀工作副本流程。首次一次讀完整 ModelSpace，後續重用本機快照；只有 refresh=true 明確重建。
2. 模型取得統計、可確認的幾何範圍、少量矩形／圓的文字總覽與 snapshot_id。完整圖元留在 Broker 記憶體，未送到模型上下文或模型工具紀錄。
3. `cad_query(snapshot_id, filter, offset, limit, details)`：依種類、圖層、ACI、文字、直徑、WCS XY 區域、Handle 或候選編號取資料。多條件 AND；分頁只針對符合結果。候選最多50筆／頁，詳細資料最多10筆／頁，內容最多100KB且不截斷單一圖元。
4. 需要精確屬性時 details=true。只有實際交付的可修改圖元才加入已讀 Handle，總覽與候選清單不算修改授權。
5. 多候選有歧義時，`cad_preview(...,show_user=true)` 顯示局部示意與清單。使用者選號碼或關閉；選擇綁定快照及 Handle，修改仍需要原本的文件確認。
6. 品質模型可用 show_user=false 只生成 JPG，再明確 analyze_image；預覽本身不自動上傳。快速模型只允許 show_user=true，圖片工具與傳圖說明移除，後端亦拒絕圖片辨識。
7. `cad_active_edit` 或 `cad_edit` 沿用 revision／Handle／原件保護及修改後核對。目前圖面不儲存、不關閉；寫入開始即作廢目前快照，後續需要時重新建立。

## 幾何與查詢約定

- 座標為 WCS；XY 預覽 X右/Y上，與使用者目前旋轉視角不一定一致。距離是圖面單位；INSUNITS=4 才標示毫米，未知不猜。
- 圓提供圓心與直徑，不需把十個取樣點交給模型。矩形只辨識可確認的閉合四角輪廓（直線折線或四條獨立線），初版限平行 WCS XY 軸、同一高度。
- `filter.rectangle` 是總覽內矩形編號，用來計算同平面圓的圓心距離、圓外緣間隙與完整包含關係；它不是篩選條件，也不推論哪個輪廓是底板或孔的用途。
- region 為 `[xmin,ymin,xmax,ymax]`，以已知幾何外接框相交篩選；不是精確碰撞、三維干涉或螢幕框選。未知範圍的圖元另計 unavailable，不視為已排除。
- 初版預覽畫線、XY 圓與可讀直線折線，最多2000個背景圖元／20000段背景線，所選候選最多20個，優先顯示。960×640，等比例投影；紅色為候選、灰色為周邊，號碼與工具候選一致。
- 預覽不呈現原始顏色、線型、文字、尺寸、引線、剖面及圖塊內容；明示省略數量。這是幾何示意，不是原生 CAD 截圖，也不能用像素量測。折線缺少法向量、bulge／座標資料或過大時不猜測形狀。
- 候選編號使用快照內固定位置，並非每次查詢重新從1編號；不同查詢仍能指向同一 Handle。重建快照後必須使用新的 snapshot_id。

## 新鮮度、續接與安全邊界

- 固定且逐檔雜湊鎖定的 LISP 在 CAD 程序內匯出原生 DXF 資料；Python 一次解析成本機索引，模型不負責接續批次。直線、圓、弧、文字、直線折線及圖塊基本資料直接轉換；傾斜 OCS、擬合折線、未知圖元與必要屬性沿用 COM 詳讀。保留傳統折線頂點及圖塊屬性，2008 的附屬 ATTRIB Handle 也納入集合。
- 明確數量不符時完整 COM 備援，每批 50 圖元累積本機資料。逾時、無完整結尾、格式錯誤不自動重送。進度為實際匯出／描述數量，CAD 回報數量另外顯示，不換算為保證完成的百分比。
- 讀取、新建與修改工作含核對最多 600 秒；輕量 inventory／probe 維持 240 秒。讀取期間顯示非模態提示、數量、經過時間及取消任務按鈕，工作結束自動收起。快取查詢及模型思考不顯示此提示。
- 批次間核對作用中文件物件及可觀察的名稱、路徑、數量、單位、DBMOD；不把 DBMOD 當通用遞增修改序號。取消／失敗不發布部分索引，不自動續讀；終止自己的 Python 不代表能立即中斷 CAD 伺服器內部尚未返回的呼叫。
- COM 物件依 Handle 延後取得，修改與核對優先使用已匯出資料；缺少適用屬性才詳讀。仍保留圖層、顏色、線型、比例、厚度、適用幾何及法向量；未指定圖元另比較原生資料雜湊。不採用多條 COM 執行緒同讀一個文件。

- 作用中查詢只做輕量文件身分／ModelSpace Count／INSUNITS 核對，不重掃全部圖元。同數量的手動移動或改半徑可能無法即時偵測，因此結果明示是快照資料。
- 修改前仍由原生 worker 重新取得全部可讀圖元、圖層鎖與 revision。任何不符都停止，不能自動把舊計畫換成新 revision 重送。文件切換、來源檔雜湊變更、寫入或重新啟動後舊候選失效。
- 同一 Broker 的上下文整理保留完整索引；暫停後重建 Broker 不恢復作用中快照與寫入授權。舊快照工具的快取只作歷史，不能當作可用候選。
- 每輪模型固定收到精簡索引／可用性；不靠 AI 筆記記住全部點位。重查相同資料或重建同一 revision 不算新進展。
- 預覽 JPG 存於新的 `_AI_Output/<唯一資料夾>/cad-preview.jpg`，讀回核對；圖片只在本機顯示或明確品質模型辨識時使用。生成記錄綁定 snapshot_id 與 SHA256，檔案變動或快照失效時不得新上傳。已提交未知結果的圖片請求仍只查原ID，不因快照失效重送。
- 快照最多20萬圖元／約64MiB索引。大型讀取仍可能逾時；不把功能實作當成效能已驗證。

## 後續驗證

實作階段依暫停建置要求只做格式整理；恢復發行後依專案流程執行編譯及既有契約／整合驗證。通過建置不等同 CAD 實機與模型答案準確性驗收。

每次 CAD worker 變更後，先執行 `python tools/build_cad_runtime.py` 重建並核對固定來源 runtime，再使用 `scripts/Build.ps1`（v142 x64、空Cargo快取、--frozen）。不得沿用舊 runtime 清單發布新腳本。

需覆蓋：快／品質工具與技能差異、同直徑多候選、局部預覽指認／取消、同數量手動改圖、切換文件、revision過期、細節查回後修改、來源副本保護、重啟失效、查詢與預覽上限、候選編號跨查詢一致、WIC轉檔、圖片原ID查回及2008／2022實機相容。

自動測試、原生 2008／2022、Luna GUI 及安裝生命週期的實際結果，統一記錄於本版驗證文件。合成圖驗證不代表真實建築圖的外參、代理物件與所有視覺外觀已驗收。
