## 顯示方式

- 每輪合法模型回覆的 `progress_note` 以「AI 進度筆記」顯示，空白筆記不顯示。它是模型提供的工作摘要，不是內部思考過程或已執行的證據。
- 執行中只顯示最新一份累積筆記，保留換行，長內容可捲動；各次筆記與中途說明沿用現有加密工具活動紀錄（最近 120 筆、每筆最多 2048 字）。不額外要求 AI 回覆，也不是逐字串流。
- 首輪還沒有工具結果時，可顯示模型提出的工作方向；顯示不改變原有工作筆記採用、上下文縮減或操作核對條件。
- 完成、暫停、等待補充或失敗後，筆記與中途說明放在答案旁預設收合的「查看工具紀錄與進度筆記」。重新開啟對話亦從該區查看；正文、複製答案與成果維持分開。
- 切換對話只顯示該對話的任務；模型未提供筆記時，維持既有工具進度顯示。筆記作純文字，不解譯 HTML 或可執行連結。
