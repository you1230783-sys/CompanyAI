# 0.3.0 驗證範圍

本機目標為 Windows x64、Rust 1.98.1、MSVC v142 14.29.30133、Windows SDK 10.0.19041.0。
本文件說明驗證方法；實際成功記錄與交付檔案 SHA256 見同版 `offline/environment.txt`、`manifest.json`、`verification.json`。

## 自動化檢查

`scripts/Build.ps1` 執行格式、Clippy（warnings 視為失敗）、22 項測試、release 建置、EXE 隱藏控制項自我檢查及 DLL 依賴檢查。
測試涵蓋：

- 固定端點不能被舊偏好 JSON 覆寫、同來源限制、登入與模型變更的憑證綁定。
- 版本按數值比較、初次查詢失敗可用、已知強制更新後失敗仍阻擋、錯誤版本資料不覆蓋已知狀態。
- 模型 alias、預設選項、未知偏好回退、重複 id／不存在的預設拒絕。
- 本機 WinHTTP GET 版本／模型 → 一次性登入 → Bearer Chat Completions，驗證 alias、stream=false、X-Client-Version 及繁體中文回覆。
- 登入拒絕、到期、取消、重複兌換、兩種底層 Header 的相容性、redirect 拒絕與 DPAPI 保存。
- 快捷鍵格式、保留／含糊組合拒絕、擷取文字長度及 UTF-16 結尾檢查。

EXE 自我檢查會建立真正 Win32 控制項，確認模型代號對應顯示名稱、版本斷線時送出按鈕可用，以及已知強制更新後按鈕停用。
它不顯示主視窗、不註冊快捷鍵、不操作系統剪貼簿、不登入或連線，也不保存個人資料。

`scripts/Prepare-Delivery.ps1` 再將完整 ZIP 解壓到全新位置，以包內 Rust 工具鏈、空 Cargo 快取及 `cargo build --frozen` 所在的完整 Build 流程重驗。
包內保留 Cargo.lock、vendor、.cargo/config.toml 與 rust-src；指定 MSVC／SDK 仍由電腦預先安裝。

## 尚需公司實機驗收

本次原生桌面操作工具無法取得視窗，因此**未完成人工截圖外觀檢查、真實全域快捷鍵與跨應用選字測試**。
下列項目不可由單元測試推定已通過：

| 情境 | 預期結果 |
| --- | --- |
| 100%、125%、150% 顯示比例與縮放視窗 | 側欄、對話、模型及輸入區可閱讀與操作 |
| 按登入、在瀏覽器授權、返回 | 短碼相同、完成後顯示已登入與模型 |
| 瀏覽器／Word／Classic Outlook 選文字、Ctrl+Alt+Q 並放開 | 先複製來源文字，再顯示草稿；尚未呼叫聊天 |
| 來源 Ctrl+C 沒有產生新文字 | 顯示擷取失敗，不使用舊剪貼簿內容 |
| 保持按住修飾鍵、切換來源視窗、剪貼簿被別的程式改動 | 停止本次擷取，提示重試 |
| 來源以管理員權限執行 | 可能受 UIPI 限制；清楚提示可手動複製貼上 |
| 已有草稿後再次擷取 | 接在後面；超長不覆蓋原稿 |
| 修改快捷鍵／與其他程式衝突 | 成功後生效並保存；衝突提示，盡力恢復原組合 |
| 翻譯／摘要／潤飾／Ctrl+Enter | 每次明確操作只送一次，回覆可複製及追問 |
| 關閉程式後按快捷鍵 | 不再啟動擷取 |
| version 暫時 503，但登入／models／chat 正常 | 首次檢查失敗仍可使用 |
| minimum_version 比桌面高 | 提示開下載頁，停止新的登入與聊天 |
| 公司 DNS、代理、SSO 與實際模型 | 完成真實內網往返，不以本機 demo 代替 |

第一版擷取採 Ctrl+C，會改寫剪貼簿；不保證所有應用程式的剪貼簿擁有者行為相同。
某些編輯器沒有選取範圍時仍會複製整行，桌面無法僅憑剪貼簿區分；請核對草稿後再送出。
若特定應用因複製代理程序或其他限制被拒絕，先使用手動貼上，後續再針對公司常用程式評估 UI Automation 等替代方式。
