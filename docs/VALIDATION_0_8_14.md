# 0.8.14 EXE／NSIS 驗證紀錄

驗證日期：2026-09-24。先交付 EXE 後，使用者已回報測試成功並授權製作 NSIS；本次維持 0.8.14，補齊安裝包及更新清單。

## 本版行為

- 匯入預覽的分類依字母與數字自然排序，例如 A01、A2、A10、B01、Z99，未分類最後。同分類機台依 A01-01、A01-2、A01-10、A01-AA、A01-AB 排序；匯入時也排序本次有新增／更新的分類內機台。原有手動上下移動仍可使用。
- 名稱跨分類比對本機設定；同名同 IP 標綠、取消勾選並停用，同名不同 IP 標紅且可選，新名稱維持一般項目。整類勾選跳過一致項目，整類一致則分類也不能勾選。
- 成功取得清單後保留同一個 PHPSESSID；匯入成功或捨棄後才登出。首次未分類達 50%（含一半）自動重取全部 API 一輪，**最多一次**；手動「再次取得更新清單」每次只重取一輪、不重登入、不再追加自動重取。
- 每次請求前仍等待 300ms。每輪完整取代預覽並清除勾選，舊預覽 ID 或清單版次不得匯入。取消、停用、通道中斷、API 錯誤及正常退出均嘗試登出；正常退出等候背景工作結束。強制終止程序不能保證登出。
- 既有密碼、個人分類及未選機台保留。對應優先使用同來源 ID，再以本機唯一名稱對應；同名不同 ID 的新機台不會在同一批互相覆蓋，無法唯一對應時拒絕寫入。
- 提示改為使用者指定的「勾選整個分類，或只勾選需要的機台。未勾選項目會捨棄，不會刪除已儲存的機台。」

完整操作見 [VNC 快速連線](VNC_QUICK_CONNECT.md)。

## 驗證方式

執行 `scripts/Build.ps1 -EmptyCargoCache -IncludeInstaller`，使用專案 Cargo.lock、vendor 與 .cargo/config.toml；EXE 與 NSIS 使用相同版本及原始碼。

- MSVC v142 x64：14.29.30133，實際編譯探針 `_MSC_FULL_VER=192930159`。
- Rust 1.98.1，Windows SDK 10.0.19041.0。
- rustfmt、Clippy（警告視為錯誤）、106 項 Rust workspace 測試、空 Cargo 快取 `cargo build --release --frozen`、WebView2 DOM 自我檢查，以及 EXE 更新清單簽章驗證。
- 實際 WinHTTP 對本機模擬 HTTP 服務測試：50% 自動重取一次、第二輪仍達門檻不再自動請求、預覽不登出、手動重取不重登入、Cookie 更新、結束／取消／重取失敗登出。另測試空清單與低於門檻不觸發重取。
- 以 8,112 行／1,902 行、300 台／70 台模擬回應，逐筆檢查下載、解析、預覽 JSON 與匯入後重載，370 台 IP 保留。
- 原生測試覆蓋自然排序、名稱比對、完全相同項目不重匯、跨分類唯一名稱更新、密碼保留、同名新機台保留、歧義匯入拒絕。
- DOM 自檢覆蓋綠／紅標記及提示、停用相同項目、整類排除一致項目、Session 期間鎖住帳密／網址、手動重取命令、重取或本機資料改變時清除舊勾選。

本機模擬服務明確將接受的 socket 切回 blocking，避免 Windows 並行測試繼承 listener 非阻塞模式而偶發 WouldBlock；未修改正式 WinHTTP 的通訊設定。
