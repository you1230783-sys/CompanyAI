# 0.8.23 專案記憶與 PDF 快取

## 儲存與目錄界線

首次送出專案任務時建立專案根目錄下的隱藏 `.lmai`。一般聊天不建立、不附帶專案記憶。

| 位置 | 內容 |
|---|---|
| `.lmai/project/index.dpapi` | 專案／對話筆記、文件及任務索引 |
| `.lmai/documents/<來源鍵>.dpapi` | 來源版本、可按段讀回的文字、全篇及分段摘要 |
| `.lmai/runs/<任務 ID>.dpapi` | 原始要求、完整結果、狀態、成果路徑 |
| `.lmai/cache/<內容鍵>.dpapi` | PDF 轉換 Markdown、來源及轉換設定、內容 SHA256 |
| `.lmai/store.lock` | 獨占交易鎖，不含文件內容 |

全部內容以目前 Windows 帳號 DPAPI 加密，並非明文 Markdown。直接搬到其他帳號不保證可解密；不可讀的筆記索引保留原檔並停止，不覆寫成空資料。快取不可讀則重新轉換。移除專案／對話不會刪除原始文件、成果或 `.lmai`。

一般列目錄忽略 `.lmai`（不分大小寫）；讀取、搜尋、複製、匯入及選擇專案根目錄拒絕該路徑組件，並檢查實際控制代碼路徑，避免短檔名別名繞過。私有儲存拒絕重新解析點、硬連結檔案，固定父目錄，獨占交易，以隨機暫存檔原子替換。資料只能經專用記憶工具取得，不把私有檔當使用者文件附送。

## 筆記與證據

- `list_notes/read_note/create_note/update_note/delete_note/restore_note` 提供專案或本對話筆記；修改須帶目前 revision，刪除為軟刪除，保留最近五個版本。其他對話不能讀本對話筆記／完整任務結果。
- 筆記每則最多 2000 字、標題 100 字，最多 200 則（含軟刪除）。文件最多 200 份、任務索引最多 1000 筆、私有單檔上限 8 MB；達限明確停止，不默默丟掉工作紀錄。
- 文件來源版本包含原始 bytes 指紋及使用者匯入快照指紋。每次使用文件摘要、區段原文或更新摘要，核對目前來源；變更、不可讀或刪除時不把舊摘要自動送出。
- 每段最多 4000 Unicode 字元，盡可能在段落／標題邊界切分。`list_document_sections` 每頁十段；`read_document_section` 只送指定段。這些位置是轉換文字位置，不宣稱是 PDF 原始頁碼。
- `read_file` 附目前已讀區間、相關段落及 `summary_needed`；技能要求模型摘要已讀段落，完整閱讀後建立全篇摘要。新摘要須有本次實際閱讀證據，或全篇已有全部段落摘要；快取全文存在不代表模型已讀。
- `update_document_note` 必須提供來源 revision 及 note_revision，摘要最多 1000 字。已有且仍有效的摘要可修訂；程式驗證版本及覆蓋範圍，不宣稱驗證所有語意正確。
- 專案曾登記非 MD 文件時，記憶可能帶有受保護內容，後續任務繼續要求 TXT 成果，避免透過摘要轉存為未加密 MD。

## 上下文如何組成

舊版專案將對話歷史帶入新任務；0.8.23 改為桌面 Skill、選取的記憶、最近兩個完整使用者提問、目前完整提問。記憶包含最多四則筆記、八筆本對話任务摘要／成果索引、三份文件及各四段相關摘要；合計最多 40,000 UTF-8 bytes，依最近使用及關鍵字相關性選擇，並非向量搜尋。

`finish`／`ask_user` 同一操作 JSON 可附 `task_summary`，最多 1000 字。程式自行保存實際成功、失敗、等待補充或取消狀態；摘要不具授權或完成證據效力。模型未提供摘要時保存明確標示的結果節錄，不假裝是完整摘要。完整答案、原始提問仍保留，`read_task_result(task_id, field, offset)` 每次可讀 6000 字。

舊對話第一次使用時按已有訊息建立結果索引，不額外請求模型重新摘要。重試只選截至原問題的歷史，不引入之後的失敗答案。筆記與文件摘要仍代表專案目前狀態，不是歷史時間點快照。

單次任務內沿用 0.8.22 的進度筆記、保留未摘要證據、有限修復及 60 次工具／80 次模型／30 分鐘上限。一般聊天仍最多 20 輪；專案本機歷史提高到 1000 則，但不把全部重送。後端必須尊重桌面 messages，不能另拼舊全文；240 KB 內容上限不等於模型 token。

## PDF 快取

來源 PDF 的 SHA256 加上轉換路由及固定轉換規格版本形成快取鍵，保存並核對 Markdown SHA256。來源及設定相同即可跨任務重用；來源變更、設定變更、損壞或不能解密則重新 POST。最多保存最近寫入的 20 份快取，超額移除舊快取；文件筆記與任務結果不隨快取清理。伺服器轉換成功但快取寫入失敗仍可完成當次閱讀。

沿用單一 multipart file、50 MiB、Bearer／X-Client-Version、同步 Markdown 回覆。無新增路由、無 job ID 輪詢、無圖片擷取、無 NSIS 或 Python 依賴。

## 任務與通知

桌面以一個使用者要求顯示一張專案任務卡；模型／工具往返只更新可展開歷程，不每輪浮出通知。完成、失敗或需要補充才產生一則最終通知；主動停止不額外跳通知。本機通知已讀不呼叫網站不存在的 ID。

每轮 HTTP 仍是獨立伺服器工作。桌面持久記錄 client_request_id 及 server task_id，僅隱藏 resource_id 確實對應的內部 AI／全站通知（含專案標題）。後端須回傳此關聯，缺失或其他 ID 不猜測隱藏。這不會合併網站本身的任務清單；若要網站亦僅留一張卡，需後端另外支援父子任務。

## 交付

0.8.23 僅交付 EXE、簽署 EXE 清單、原始碼及文件。使用 v142 與空 Cargo 快取 `Build.ps1 -EmptyCargoCache`；不重製 NSIS／離線 ZIP。公司加密環境及 GLM／Gemma 的摘要品質、速度仍由使用者測試。
