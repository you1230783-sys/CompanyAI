# LM_AI 使用指南

[專案首頁](../README.md) · [版本更新](../CHANGELOG.md) · [技術文件](README.md)

本文件以 **0.8.35** 為準，集中說明目前的操作方式。

## 開啟與登入

執行環境為 Windows 11 x64，需要 WebView2 Runtime；日常使用不需安裝 Rust、Node 或 Python。Office 文件功能需要對應的桌面 Word／Excel／PowerPoint，Outlook 功能需要 Classic Outlook，VNC 功能需要 UltraVNC Viewer。

1. 從 [專案首頁](../README.md) 下載 EXE，或使用 IT 提供的版本。
2. 執行 `LM_AI.exe`。若提示缺少 WebView2，安裝公司提供的 x64 Runtime 後再開啟；詳見 [離線安裝說明](../dist/WEBVIEW2-OFFLINE.md)。
3. 按「登入」，在瀏覽器核對程式顯示的短碼並允許授權。
4. 回到 LM_AI，選擇後端提供的「快速／品質」等模型。

有效登入最長保存 30 天；重新開啟時可沿用尚未到期的授權。未登入時其他功能會停用。

## 一般對話

在「最近對話」旁新增對話，輸入內容後送出。預設 **Enter 換行、Ctrl+Enter 送出**；設定可改為 Enter 送出、Shift+Enter 換行。

- 「一般」模式會逐段顯示回答；「背景處理」可從右上角任務面板查看進度與結果。
- 按迴紋針選擇附件，也可在輸入框貼上圖片。等待附件卡片顯示可送出後再分析；可用格式與大小依目前模型及後端規則而定。
- 對話會自動產生標題；滑鼠移到對話列或以鍵盤聚焦後，可改名、置頂或刪除。
- 最新提問可按「重新再試一次」。若原任務結果尚未確認，程式會先查回結果；附件過期時需重新加入。
- 支援 Markdown 表格、程式碼複製與數學公式。向上閱讀時保留位置，按「查看最新回覆」可跳回底部。

一般對話不會因為文件位於電腦中就取得資料夾存取能力；需要操作資料夾時，使用下方的專案功能。

## 專案文件工作

### 建立專案與對話

1. 在側欄「專案」區塊按「新增專案」。
2. 輸入名稱，按「選擇資料夾並建立」，選定本機專案資料夾。
3. 在該專案旁按「＋ 新對話」，輸入工作要求。

專案對話的標題下方會顯示資料夾路徑，也會自動產生對話標題。例如：

> 請列出資料夾中的檔案，讀取「報告.txt」，修訂用詞後另存副本。

> 請閱讀「研究.pdf」，整理重要結論，並註明尚未確認的內容。

執行中會顯示最新步驟，例如閱讀檔案、建立副本、編輯文字、儲存副本；點擊可展開歷程。內部工具往返不逐次新增通知，任務結束時再通知。

工具失敗時會顯示原因與操作代號。開啟「設定 → 進階功能」，選擇目前對話的任務並按「查看執行紀錄」，可查看本機保存的模型回覆、工具要求與執行結果，並重新讀取或複製，不需要先到網站找聊天紀錄。較長內容會標示截斷；舊版沒有保存的逐輪回覆無法補回。複製的紀錄可能包含文件內容，提供給他人前請先檢視。

範例：「建立測試報告.docx，包含標題、條列測試條件與兩欄結果表格。」或「新建比較表.xlsx，第一列加粗、淡藍底色，數值顯示兩位小數。」

### 大型 LOG 分析

像「約 10:00 上料」會提示 AI 先查前後約 5 分鐘，再依事件與行號回讀確認真正開始位置，必要時擴大至前後 15／30 分鐘；不反覆精確找 `10:00`。明確指定嚴格時間範圍時依指定範圍搜尋。支援只有時間的行首及時間後逗號分隔訊息，沒有可核對日期時會註明日期未知。

將 LOG 放在專案資料夾，可以直接說：

> 分析 Z01-CY 的 connection LOG，找出 2026-06-23 12:25～12:33 的連線異常，附上檔名、行號和前後文。

支援檔名 `20260623_connection_Z01-CY.log`，內文時間 `2026/06/23, 15:25:48.084`。分類、站別可指定；時間以內文為準，只有時分秒時可用檔名日期補足。每檔最多 32 MiB，每次查詢最多 30 檔，工具依結果續頁。LOG／OUT／ERR／JSONL 僅唯讀，TXT 紀錄也可使用 LOG 工具。JSONL 支援文字搜尋，尚未解析內嵌時間欄位。

搜尋摘錄有行號；需要細節可要求讀取附近原文。未查完、時間無法辨識或讀取失敗都會明示。原檔變動後需重新搜尋；正被其他程式寫入時請改用已輪替或另存的 LOG。本版不是即時監看器。

### 執行中傳送訊息

任務進行時直接在主輸入框打字，再選擇傳送方式：

| 方式 | 使用時機與行為 |
| --- | --- |
| 下一輪加入提示（預設） | 補充目前任務，例如「只看 Z01-CY，12:28 曾手動重啟」。下一輪模型請求帶入，保留原始目標；已開始的操作先完成。 |
| 停止目前任務並傳送 | 保存文字並停止原任務，等待原任務釋放後才啟動同對話的新任務。 |
| 任務完成後傳送 | 等原任務正常完成再啟動新任務，開始前可取消排程。 |

「本次任務的補充指示」可查看接收狀態，待接收項目可在主輸入框修改或撤回；已帶入後另送一則修正。每則補充最多 4000 字、每次任務最多 30 則或合計 48 KB，加密保存並支援暫停續接。

每個對話可保留一則待送新任務，最多 16000 個 UTF-16 字元；等待期間仍可補充目前任務。待送訊息綁定原專案、帳號與模型。原任務暫停、失敗、等待補充、手動停止或程式重開後保留文字，按「現在傳送」才啟動；也可取消排程。取消排程不會撤銷已發出的停止要求。

只有原生命令確認接受後才清除原文字；另打的新草稿不受影響。任務剛結束而拒絕時保留輸入文字，不自動改送另一個任務。

### 查看進度筆記

模型提供 `progress_note` 時，執行中會顯示最新「AI 進度筆記」，長筆記可捲動。這是工作摘要，更新頻率依模型回覆；不是內部思考逐字稿，也不代表所述步驟已完成。

完成、暫停或失敗後，進度筆記與中途說明收進預設收合的「查看工具紀錄與進度筆記」。最終正文及複製答案不包含這些紀錄；重開對話仍可展開查看。

### 達到上限時繼續

正式原生專案任務每段最多 24 小時，包含模型排隊及等待使用者的時間。每 60 次工具／80 次回覆自動保存 checkpoint 並換批，時間不重新計算；完成要求即交付。手動「繼續」才開始新一段時限。舊版文字協定 checkpoint 維持原有次數暫停方式。

程式在約 65% 工具文字預算或 30 對工具歷史時整理上下文，保留原始要求、補充、累積工作筆記、最近結果、檔案版本及成果索引；完整工具原文另行加密保存，可按需查回。模型會收到筆記整理提示，未提供語意筆記時仍保留程式可核對的狀態，不能憑空假造待辦或完成結果。下一次對話預設帶最近三輪的用戶要求與最終答案、各工具使用次數，省略中間往返；過長的舊答案節錄並提供原文查回位置。

等待模型及每個安全工具步驟都有加密 checkpoint。中斷後按「繼續」會核對原帳號、專案、來源與成果版本；原請求結果不明只查原 ID，不重送。修改工具執行途中崩潰時，舊 checkpoint 已失效，不會重播未知寫入。取消或正常完成後不保留可繼續狀態。到期、格式修復／無進展上限及需用戶選擇時仍暫停。原始要求本身太大無法縮減時，明確要求縮小提問，不再顯示無效的反覆繼續。

### 專案中讀取 Outlook

例如：「依本週郵件整理週報，先列出本地收件資料夾，再挑與專案有關的資料夾，補上線上寄件備份。」請先開啟 Classic Outlook。首次使用 Outlook 工具時，先在本機列出資料夾供勾選；第一次預設全選，之後沿用上次選擇。確認後，所選範圍的資料才可供目前 AI 服務使用；未勾選分支不提供 AI、不讀信、不匯出。取消不讀郵件，暫停或重啟後重新確認。

本地來源為 Outlook 已載入的 PST，涵蓋收件匣及規則移入的平行／子資料夾；不搜尋電腦上的其他 PST。寄出來源為 Exchange 或 OST 信箱的「寄件備份」，不是未寄出的寄件匣。資料夾先分層列名稱，AI 選定後按日期列標題，重要信件才讀純文字內文；同寄出時間、寄件地址與 To／CC／BCC 集合去重。無法解析地址時保守保留。查詢超過上限會標示不完整，須縮小日期或資料夾，不代表找不到資料。

每次任務 AI 最多讀 50 封內文，每封 256 KB／每頁 12000 字；另可在本機比對最多 1000 封不同郵件版本，優先讀最新信及缺口前的補充信。比對原文不送給模型。不讀附件、不寄信或修改郵件。Outlook 信箱可能使用離線快取，須由使用者確認同步狀態。

### 檔案占用與圖表核對

檔案被 Office 或其他程式占用時，提示關閉後「重試」，可接續當前工具；也可選擇保存暫停，再按繼續。程式不會強制關閉使用者文件。正在寫入的 LOG 建議先使用輪替後或另存的檔案。

圖表對 NG 等異常文字預設選「略過」，仍可在預檢改成缺值或設零；原本真正空白的格子維持缺值。圖表下方「查看異常值」列出數字文字轉換、原空白、異常處理與無效 X 排除統計，並分頁顯示 X／Y、原始值、工作表、來源列／儲存格及處理方式。舊圖沒有逐筆紀錄時會明確說明。

### 成果與原檔

原始文件保持唯讀，修改會在獨立副本進行。成果位於專案下的 `_AI_Output`：

```text
專案資料夾/
├─ 報告.txt
├─ _AI_Output/
│  └─ 20260930_143000/
│     └─ 報告_修訂.txt
└─ .lmai/
```

成果資料夾按建立時間命名，檔名保留可讀名稱，重名才加序號。點擊回答中的成果連結，可在檔案總管定位。TXT 來源不會自動改存為 MD。

`.lmai` 由程式保存專案筆記、摘要與快取，不會列為待分析文件。後續提問可以沿用摘要，需要細節時再讀回原文。

### 支援的文件範圍

| 格式 | 目前支援 |
| --- | --- |
| LOG、OUT、ERR、JSONL | 唯讀、按行分批、時間／多關鍵字搜尋，最多 32 MiB。 |
| TXT、MD | 讀取、尋找文字、建立副本、插入／刪除／替換文字與儲存。一般新文件優先使用 TXT。 |
| DOC、DOCX、DOCM | 修訂正文與表格文字；新增正文段落、條列與簡單表格，設定樣式、字型、字級、顏色、對齊、行距。 |
| XLS、XLSX、XLSM、XLSB | 讀取／修訂文字與數字、新增工作表及資料範圍、設定欄寬、底色、框線與數字格式；不覆寫公式或合併格，不修改巨集、圖表。 |
| PPT、PPTX、PPTM | 修訂一般文字框、設定字型及段落；新增標題頁、標題＋內文、雙欄投影片。操作前請儲存並關閉 PowerPoint。 |
| PDF | 由公司伺服器轉成文字供閱讀，最多 50 MiB；不擷取圖片、不保證頁碼或原始版面，衍生成果為 TXT。 |
| MSG | 使用已開啟且完成設定的 Classic Outlook 讀取標頭與正文，不讀附件；衍生成果為 TXT。 |

可直接要求新建 DOCX、XLSX、PPTX，不必準備來源檔。既有文件仍建立同格式副本；原檔不變。第一版格式以整段、文字框或儲存格範圍為單位，版面、分頁、混合字型與文字溢出仍需檢查。專案文件工具尚不提供圖片分析；一般對話的圖片附件則依模型能力提供。

### 文件讀取失敗時

公司加密、權限或檔案格式可能影響直接讀取。若 TXT、MD、PDF 或 MSG 可在核准閱讀器正常顯示，可以：

1. 開啟文件並複製全文。
2. 點專案齒輪，選「匯入文字」。
3. 選擇對應的專案內來源檔案，把全文貼入輸入框後保存。
4. 回到對話，補充說明已匯入內容，再繼續任務。

匯入的是當時的文字快照；原檔變更後，請重新匯入或在專案設定清除匯入文字。這個方法不會保留 Office 排版。PDF 伺服器轉換可能需數分鐘，請先查看目前狀態。

### 專案設定與移除

專案齒輪可編輯名稱、匯入文字或移除專案。移除時可選擇將對話移到一般對話，或一起刪除；兩種選擇都不會刪除原始文件與已產生的成果。

專案工具需要 LM_AI 保持執行，可縮到托盤；真正退出後，不會自動重播尚未完成的本機檔案操作。

## Outlook 助理

先開啟並完成 Classic Outlook 帳號設定，再從 LM_AI 側欄進入 Outlook 助理。

1. 讀取選取郵件，或依日期條件取得郵件清單。
2. 核對預覽並勾選本次要分析的郵件，再送出分析。
3. 若只分析基本資訊，使用目前選擇的模型；單封手動模式要讀正文時，需另外勾選並確認。
4. 若勾選「允許 AI 從本次送出的郵件，挑選可能重要的信件後，自動要求詳細內文並自動送出」，整個流程從初篩起使用品質模型，並只處理本次已授權的郵件。

助理不寄信、不刪信、不移動郵件，也不修改未讀狀態。自動補充郵件內文期間須保持程式開啟；退出後需要重新確認授權。

## 選取文字快捷鍵

保持 LM_AI 開啟，在來源程式選取文字後按 **Win+Esc** 並放開按鍵。文字會加入草稿，確認後再送出、翻譯、摘要或潤飾。

設定可修改或停用快捷鍵，也可啟用預設關閉的浮動 AI 圖示。快捷功能不會自動送出；複製會改變剪貼簿，某些編輯器未選字時可能複製整行，請確認草稿內容。

## VNC 快速連線

1. 登入 LM_AI，在設定的「使用習慣」勾選「啟用 VNC 快速連線功能」。
2. 確認電腦已安裝 UltraVNC Viewer，必要時指定 Viewer 路徑。
3. 使用「機台管理」整理分類與機台，點擊機台卡片連線。
4. 需要同步清單時，按「機台管理」左側的「從網站更新」，再於彈窗登入、取得、預覽並勾選要匯入的項目。

開啟彈窗不會自動登入或同步；不需要經常更新時，關閉彈窗即可。舊工具的 `machines.json` 與 `user_config.json` 可放在 EXE 同一資料夾沿用。詳細管理與設定格式見 [VNC 說明](VNC_QUICK_CONNECT.md)。

## 通知、托盤與更新

右上角可查看通知與任務。通知中心只顯示摘要，完整內容回到對話查看；專案浮動提示約三秒後隱藏。Windows 提示在 App 不在前景時顯示。

最小化或關閉視窗會縮到系統托盤；托盤右鍵選「離開」才真正退出。一般聊天已被伺服器接受的任務，重開並登入同帳號後可查回結果；這不代表專案本機工具或 Outlook 匯出能在退出後繼續。

有新版本時，設定齒輪旁會出現下載箭頭：

- 提供 NSIS 更新包時，一次確認即可下載、驗證、關閉程式、安裝並重新開啟。
- 僅提供 EXE 更新時，依畫面提示下載並手動替換；替換前從托盤離開舊版。
- 相同版本優先 NSIS，版本較新者優先。版本低於網站要求的最低版本時，需先完成更新。

目前最新 EXE 是 0.8.27，Git 的 NSIS 安裝包仍是 0.8.15。

## 設定與資料保存

左下齒輪可調整字體、深色模式、快捷鍵、送出方式、通知與其他使用偏好。

對話與登入資料保存於目前 Windows 使用者的本機資料中；草稿在切換對話、縮到托盤及正常退出時保存。登出保留本機歷史，但再次送出舊對話時，會使用目前登入的帳號。刪除本機對話或任務卡片不會刪除伺服器紀錄。

資料位置、加密與開發診斷見 [開發說明](DEVELOPMENT.md)。

## 專案技能與圖表

執行中的「AI 進度筆記」顯示最新工作摘要；完成後與中途說明收進「查看工具紀錄與進度筆記」，不加入最終答案的複製內容。模型未提供筆記時維持工具狀態顯示。

專案與最近對話標題可分別收合，重開程式仍保留偏好。可以直接在專案中說：

- 「閱讀這兩篇論文，整理實驗條件、主要數字、限制與出處。」
- 「以 W39 週報為基礎，只加入本週郵件與實驗結果，另存 W40。」
- 「將這幾份報告整理成 Excel，每列保留來源與缺漏資訊。」
- 「搜尋這幾份文件中提到速度的段落。」
- 「用這份 Excel 的第一張工作表 A1:C20 畫趨勢圖，標明單位。」
- 選品質模型後：「請快速模型先分段摘要這篇論文，再核對重點。」

圖表直接顯示在對話，可縮放並展開分頁資料表，重新開啟對話仍可查看。Excel 可指定表頭列、橫軸欄及數值欄；數值欄接受數字、Excel 提供的公式數值、明確的數字文字（如「339」）與空白。遇到 NG、X、格式不明、錯誤或合併格，程式會按欄位列出數量與範例，請選擇保留缺值、略過或設為 0。原空白仍保留缺值；類別軸「00123」不變成數字。需要放進報告時，可要求先存 PNG，再插入 Word／Excel／PPT 的工作副本並儲存。

Excel 支援選欄閱讀。例如：「先看這份 Excel 的表頭，只讀 A、F 欄，各讀 100 列，再依需要繼續。」模型可以分批讀取大表，不必先載入整張表；原檔變動後會要求重新核對版本。一般文字閱讀每批合計最多 2,000 個資料格，圖表可直接取得最多 10,000 筆資料及 8 個數值系列，不需把全部數值先傳給模型。大型文件的編輯限制維持原狀。

若需要圖片，可直接要求：「以 A 欄為時間、F 欄為數值，畫出全部 2,000 筆趨勢，並儲存為亮度趨勢.png。」模型可呼叫圖表匯出工具，產生 1600×1000 的 PNG，保存到 `_AI_Output` 並在成果中提供連結。同名檔案會加上序號；匯出包含完整選取範圍，不受聊天室當下縮放位置影響。新專案需要網站啟用原生工具能力；詳見 [0.8.31 驗證紀錄](VALIDATION_0_8_31.md)。

快速模型僅取得所指定文件的區段與摘要焦點，不取得其他對話或修改工具。已完成區段與相同版本摘要會重用；暫停後按「繼續」。摘要仍可能遺漏或誤讀，重要數字應回查原文。

### 插入 PNG 圖片

例如：「把剛剛的趨勢圖存成 PNG，插在週報文末，另存週報副本。」也可指定 Excel 的工作表與起始儲存格，或 PPT 的投影片與位置。支援新建文件及既有文件副本；圖片嵌入文件，交付後不需要附帶原 PNG。

目前只接受專案內 PNG（包含產生的趨勢圖），最多 8 MiB、1600 萬像素，寬高各不超過 8192。圖片等比例調整；Word 以獨立段落插入，Excel 為浮動圖片，不改儲存格內容，PPT 需先有目標投影片。插入功能不代表 AI 能辨識圖片內容；原 PNG 在另存完成前需保持不變。

### 圖表資料選擇

「保留缺值」讓折線中斷；「略過此點」讓前後有效點接續，但保留原本的 X 位置，其他系列不刪除資料。「設為 0」只處理所選異常群組，不更動真正的空白。若 X 無法作為座標，只能確認排除該整列，所有系列同步處理。全部處理僅用於圖表，不修改 Excel。

不想立即決定，可選「暫存，稍後決定」，之後在對話按「繼續」。來源變動時會重新核對，不能沿用對舊資料的選擇。圖表與匯出 PNG 附資料處理摘要。

專案技能會依需求載入。初始只提供瀏覽、閱讀、載入技能、查舊結果、詢問及交付工具；文字修改、Office、Excel、研究、筆記與圖表等完整用法於需要時加入，任務續接會保留。

## 本地 CSV 與較短的工作上下文（0.8.36）

畫 Excel／LOG 圖時，AI 先檢查少量樣本與欄位，再讓本地工具擷取資料並儲存 CSV。例如：「找 10:00 上料附近的壓力資料，確認開始位置，存成 CSV，再畫散佈圖。」CSV 自動放在專案 `_AI_Output/時間資料夾/`，不覆寫原檔。

對話只帶資料集路徑、版本、欄位、筆數、數值／空白統計和前後各 10 筆預覽；完整資料不重送。畫圖直接讀 CSV，包含指定範圍的中間資料，並沿用異常值選擇與「查看異常值」。該表可追到原檔、工作表、原始列／LOG 行號與 CSV 資料列。

若欄位抓錯，可在主輸入框使用預設「下一輪加入提示」，例如：「剛才壓力應用 F 欄，C 欄的圖無效，請更正。」程式會在安全界線縮短舊工具內容；AI 可再用 `compact_context` 記錄正確欄位、失效結論及下一步。CSV 已有 F 欄就直接重畫；缺欄才重新擷取。

也可以直接說：「請先保存工作筆記並整理上下文，再繼續。」原始要求、補充、已完成操作與資料檔仍保留，舊工具結果加密存於本地，可按需查回。已送到後端的那一輪仍須等待完成或透過既有停止功能結束；整理不會縮短伺服器排隊時間。

每次 LOG 擷取最多 30 檔（單檔仍為 32 MiB）、250000 筆、16 欄、CSV 64 MiB。支援固定分隔字串、前後標記、當日秒數，不執行正規表示式或腳本；未知格式需先確認樣本。Excel 每份 CSV 最多 10000 列、9 欄、90000 格。單圖最多 10000 點、8 系列；過量時需分批或縮小範圍，不自動抽樣。時間秒數為當日值，跨日分析需另行確認。

CSV 前六個 `__` 欄保存來源與型別／原顯示文字；後面是選取資料，Excel 用原欄字母、LOG 用擷取欄名。公式只保存當次 Value2，數字完整精度保留；看似公式的字串以可還原的單引號保護，作圖讀回原字串。資料集讀取器針對本工具生成的 CSV，不是任意 CSV 匯入器；手動更改 CSV 會使舊版本引用失效。跨任務可用路徑重新檢視目前版本及首尾預覽，不必重讀全部原始 LOG。


## 0.8.37 Outlook 資料夾與週報

專案需要Outlook時，先在本機勾選可供AI使用的資料夾。第一次全選，可整個取消私人分支；之後保留上次選擇，於下一次授權畫面調整。確認開放範圍，不會一次送出全部郵件。未勾選分支不提供清單／正文／MSG匯出，Outlook助理也遵守設定。

模型先選相關討論串，本機最多比較1000封純文字前文，只回字數和建議閱讀；AI最多讀50封，優先最新信、必要時補讀前文缺口。字數增加不代表完整；格式差異可能建議多讀。週報資料足夠即製作，不以讀滿額度為目標。

本機比較另有64MiB／120秒上限，未完整掃描會標明，不把它當完整信箱分析。設定改變後請使用新對話；已送出的對話、筆記與使用者匯入檔案不會自動撤回。允許郵件的引用也可能包含其他資料夾的舊信文字。PowerShell仍未開放。詳見[規則與驗證](VALIDATION_0_8_37.md)。
