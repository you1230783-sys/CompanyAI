## 修正過程與保留失敗

1. 首輪全測試：477項通過，既有CAD已載入DLL清理案例失敗；單獨執行通過。改為獨立子程序並核對實際模組路徑，避免其他WIC／COM測試共用loader狀態。正式清理邏輯沒有改動，獨立commit留存。
2. 首次原生截圖自檢使用未授權的合成Token呼叫示範API，得到401。控制器驗證改用明確的合成能力資料；網站傳輸仍由既有loopback附件測試驗證，不宣稱公司模型已測。
3. 原生測試抓到預覽期間長時間持有祖先目錄鎖，導致圖片成功保存後草稿保存失敗。改為預覽記錄目錄身分，真正寫入時固定路徑並重新比對；沒有放寬重解析點、同名覆寫或來源保護。
4. 最終補測曾與仍執行中的project_smoke共用target，linker回報LNK1104（測試EXE占用）。保留失敗紀錄，後續Cargo與原生驗證改成依序執行，不把這次編譯算通過。
5. 框選逾時也需還原主視窗顯示錯誤；已補上處理及取消狀態驗證。
6. 相容性審查補上既有選字快捷鍵優先：若使用者原本設定Ctrl+Alt+S，不搶用該組按鍵；錄製快捷鍵期間暫停截圖快捷鍵。

### 新功能人工驗收步驟

1. 在一般對話選擇支援圖片的模型，按「截圖提問」或Ctrl+Alt+S，先核對目的地，再框選測試畫面。預覽取消時不應出現附件；確認後應出現附件，仍需自行送出問題。
2. 切換快速模型，應在啟動框選前提示不支援。框選後改換對話／帳號／專案，再按確認，舊預覽應失效。
3. 在專案內確認截圖，應在受控輸出資料夾新增JPEG，原文件不變，路徑只加入草稿；實際分析才使用任務圖片額度。取消及逾時後應能繼續操作介面。
4. 在不同螢幕／DPI重複框選；若原選字快捷鍵設為Ctrl+Alt+S，原功能應優先，截圖仍可用按鈕開啟。開始錄製快捷鍵時不應被截圖攔截。
5. 建立含參數的範本，預覽後填入草稿；匯出先檢視確切JSON，移除私人內容後才分享。重新登入／重開後確認收藏與內容仍在；匯入含額外權限欄位的JSON應整批拒絕。
