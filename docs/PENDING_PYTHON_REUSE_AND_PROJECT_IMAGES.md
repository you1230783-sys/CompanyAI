# 0.8.43 設計紀錄：Python 更新沿用、專案圖片與座標轉換

使用者後續已授權進版與部署，本紀錄的修改納入 0.8.43。檔名保留以維持既有連結；最終成品與驗證狀態見 [0.8.43 驗證紀錄](VALIDATION_0_8_43.md)。

## Python 更新

新版安裝器先以待安裝 EXE 執行 `--python-self-check`，核對已安裝環境的完整清單、SHA256、套件及實際隔離分析能力。完整且相同時沿用 `python/`，不搬移或覆寫套件；失敗時走完整暫存、驗證、切換及回復流程。

主程式版本與 Python 指紋分開，主程式進版不會自行使 Python 過期。目前 worker 腳本仍屬環境指紋的一部分，修改腳本或套件會完整替換。不逐檔混補套件，不採用系統 Python。安裝包仍包含完整 Python 供離線首次安裝／修復，這項最佳化不縮小下載大小。

`Test-Installer.ps1 -ValidateOnly` 使用隔離目錄與測試安裝包，不改正式安裝器與發行紀錄。詳細方式見 [Python 環境文件](PYTHON_RUNTIME.md)。

## 專案圖片

使用者已澄清「附件」是指專案資料夾內的圖片；Outlook 助理、郵件附件、一般聊天的附件流程均未修改。

- JPG／JPEG／PNG 與其他專案資料一起列出，增加圖片類型及 `analyze_image` 工具導引。列目錄不讀取或上傳圖片內容。
- AI 依任務與現有資料自行判斷是否需要看圖，按需載入 `image-read`；不用先點快速入口，也不因有圖片就全部辨識。保留「圖片辨識」按鈕供使用者直接指定單張圖片。
- `read_file` 誤用到圖片時，唯讀驗證檔案及格式，只回中繼資料、`content_read:false` 與工具導引；不自動送圖，也不冒稱已辨識內容。
- 每次圖片子請求只送一張，單張最多5,000,000 bytes、8192×8192且總計1600萬像素，不自動壓縮。每任務最多20次不同辨識要求，包含同圖不同焦點；相同來源／焦點的完成快取不扣新額度。快取命中、原請求續查、父子對話關聯及 DPAPI 未知提交保存規則沿用。
- 後續主對話只帶文字重點及來源，不重帶原圖。fast 仍不支援；Office／PDF／MSG 內嵌圖、掃描 PDF 與網路圖片不在此範圍。

## 異常值選擇示意

異常 Y 值的選擇視窗加入三張相同座標的五點折線圖，以 X＝1、2、3、4、5，Y＝10、20、NG、40、50 示範保留缺值、略過此點與設為0。每圖均有文字說明，並標示為假設資料；略過保留原 X 位置、不新增量測點。無效 X 僅能排除整列，只有這類問題時不顯示 Y 值示意。沿用原本的選項、預設與原生決策流程。

## X／Y 座標轉換

使用者後續要求兩軸都加入平移及重新編號。使用者提供的紀錄顯示，AI 已寫出「X＝序列，從1開始」，但既有欄位核對只允許原始 A／Index、D／圖樣Mean值，因此拒絕了改用衍生序列的請求。

- 保留 CSV／Excel 真實來源欄位的驗證；新增 `transform_chart(chart_index,transform)`，先正常建圖、再從原點陣衍生座標，不新增假 CSV 欄位、不手抄數列。工具共49項。錯誤提示及三份圖表／Excel技能也加入這個合法流程。
- 編輯器與 AI 共用 `original`、`offset`、`index` 的有限設定。X／Y 均為圖上的實體軸；水平長條圖的 Y 是類別、X 是量測值。切換方向時使用者設定隨資料交換軸，不意外把類別編號套到量測值。
- `offset` 加上固定數字；`index` 以起點及非零間距依保留列順序重新編號。每次均從原始資料計算，不累加上次位移。文字／日期類別不可直接平移，但可明確改為序號。長條類別仍等距；折線的衍生數值座標改用數值軸。
- `drop_empty` 只移除所有系列都缺值的位置，0 保留。先移除、後轉換；兩軸及所有系列使用同一保留列順序，單一系列缺值仍保留，不補成編號值。完全無資料或數值溢位拒絕套用。
- 原始點陣與 CSV 不變；資料表明示為原始值。圖上軸名與處理摘要、PNG 來源說明均標示轉換。修改轉換／圖型後重設顯示範圍及參考線座標，避免沿用失效位置。量測軸重新編號會改變資料意義，需使用者明確要求。
- 使用者設定沿用 DPAPI 歷史保存；「恢復原樣」回到 AI 交付圖的設定。AI 的轉換保存在圖表中，原始座標仍可在編輯器選擇保留原值還原。PNG 去重納入圖表完整版本；轉換後重新匯出不會取得舊 PNG，也不覆寫已產生成果。
