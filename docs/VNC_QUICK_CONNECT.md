## 網站手動同步

仍先在設定勾選「啟用 VNC 快速連線功能」。開啟 VNC 頁面後，輸入網站帳號／密碼；可按「儲存登入與連結設定」記住資料，或直接按「更新機台清單」保存並執行一次同步。密碼輸入框留空代表沿用已存值，「清除已記住的登入密碼」則移除保存值。不會因啟動程式、切換頁面或計時器自動同步。

登入資料與連結以目前 Windows 使用者的 DPAPI 加密保存在 `%LOCALAPPDATA%\CompanyAI\vnc-sync.dpapi`，不寫入 machines.json；既有密碼不回傳 JavaScript，畫面以「已記住密碼；留空沿用」提示。修改網站主機後須重新輸入密碼，避免沿用另一站的憑證。Cookie 僅存於當次背景工作，不保存至磁碟、不與 AI 登入或瀏覽器共用。

「詳細設定」提供根目錄、首頁／登入／登出相對連結，以及十個機台 API 欄位；空白 API 跳過。預設根目錄為 `http://lmmes.largan.com.tw/transdata`，首頁為 `?p=machineInfoMap&v=2`，登入／登出為 `login.php`／`logout.php`，前兩個 API 為 `api/machine/info_map.php?floor=2F` 及 `api/machine/info_map.php?floor=4F`。連結只能留在設定的同一網站根目錄下，支援查詢參數；更改連結不需重新編譯。

按更新後，先 GET 首頁取得 PHPSESSID，再 POST `uid`、`pwd`、`type=1` 至登入路由，改用登入回應的新 PHPSESSID 依序 GET 清單，保留 Session 供預覽與重取；按「匯入已選項目」成功儲存或「捨棄本次清單」後才 POST 登出。每次送出前等待 300ms，不自動重試登入／轉址；登入、API 或解析失敗及停止操作時，也會在已知 session 的情況下嘗試登出。登出失敗明確提示，不宣稱網站已結束 session；停用 VNC 會要求背景登出，正常離開程式會等候背景工作結束；關機或強制終止程序則無法保證送出登出請求。流程依使用者提供的 PHP session 行為實作，採 [WinHTTP 手動 Cookie 處理](https://learn.microsoft.com/en-us/windows/win32/winhttp/cookie-handling-in-winhttp)。

清單要求 `ok: true`、`code: 0`、`data.machines` 陣列；依 `eq_type` 分類，顯示每台 `machine_name` 與 `machine_ip`。缺 IP 顯示空白，缺分類歸為「未分類」，無名稱項目略過。不讀取 tip 等其他資料；每個回應最多 4 MiB，合計最多 10,000 台。重複 ID 內容一致時去重，衝突時停止，不用半份資料更新本機。

取得成功後只在記憶體暫存，先顯示所有分類及機台，預設不勾選。可以勾選整類或個別機台，再按「匯入已選項目」；未勾選資料捨棄，亦可捨棄整份暫存。匯入採新增／更新，保留手動機台及既有 VNC 密碼；本次有新增／更新的分類內，機台會依名稱自然排序。新機台密碼預設為 `1234`，可於機台管理更改；空 IP 可匯入／編輯，但連線按鈕停用，原生層也拒絕空位址連線。

對應優先使用網站根目錄＋machine_id（保存為機台額外欄位 `_lm_sync_source`、`_lm_sync_id`）；找不到識別碼時，以所有分類中的唯一名稱對應。再次同步更新名稱／IP，保留個人分類及密碼；重複名稱造成多筆匹配時提示先整理，不任意覆寫。網站未提供穩定 ID 時，改名可能成為新機台。

## 預覽排序、比對及再次取得

預覽分類依英文字母及數字自然排序，例如 A01、A2、A10、B01、Z99，「未分類」固定在最後。同分類機台例如 A01-01、A01-2、A01-10、A01-AA、A01-AB，字母尾碼排在數字尾碼之後。匯入後受影響分類內的機台也採自然排序；手動分類順序仍保留，沒有手動順序的分類預設採自然排序。

以 machine_name 對照本機所有分類：同名且 IP 相同顯示綠色「與現有設定一致」，不勾選且停用；同名但 IP 不同顯示紅色「與現有設定不相符」，仍可由使用者勾選；找不到名稱則維持一般項目。整類勾選會跳過一致項目，全類都一致時分類勾選也停用。多筆同名中有不同 IP 時標為不相符；匯入仍要求唯一識別碼或唯一名稱，不自行挑一台覆寫。預覽期間修改本機機台或重取清單會清除勾選，避免舊索引誤用。

每次登入的首次完整清單，若未分類占比達 50%（含剛好一半），就用同一 PHPSESSID 對已設定的全部 API 再取得一輪。**自動重取上限一次**，第二輪仍超過門檻也不繼續，空清單不觸發。使用者可按「再次取得更新清單」手動重取一輪，不重登、不追加自動重取；每輪完整取代預覽，不混用上一輪資料。預覽保留期間不可變更登入設定；Session 失效／重取失敗會結束並嘗試登出，需要重新按更新登入。

## 批次機台管理

管理表格提供個別機台勾選框及「選取整類」。機台上／下移可將多台選取的機台在各自分類內移動一步，保留相對順序；分類上／下移則調整已完整選取的分類頁籤。刪除已選項目前會確認，支援多台及整類。分類順序保存在 `user_config.json` 的 `group_order`，machines.json 的分類物件格式不變。所有操作保留既有版次及外部修改檢查，儲存失敗不變更記憶體。

## 開啟功能

在「設定 → 使用習慣」勾選「啟用 VNC 快速連線功能」，側欄才會顯示入口。舊設定與全新設定一律預設關閉；此偏好保存於各 Windows 使用者原有的 CompanyAI 設定。

未啟用時不讀取 VNC 機台檔、不啟動搜尋或連線，原生層也會拒絕 VNC 命令。停用會關閉 VNC 管理畫面並清除已載入的機台狀態；已開啟的 UltraVNC 視窗維持獨立運作。這是本機工具，不需要 AI 登入，但仍受應用程式既有最低版本門檻約束。

## 沿用 Python 設定檔

固定讀寫 **目前執行的 LM_AI.exe 同一資料夾**：

- `machines.json`：機台分類、名稱、位址與密碼。
- `user_config.json`：Viewer 路徑與連線選項。

正式安裝位置目前為 `C:\largan\LM_AI`，因此可將原工具的兩個檔案直接放到該處，不必重新填寫機台。開啟 VNC 頁面後可按「重新讀取設定」。沒有機台檔時顯示空清單，不建立示範機台；新增機台並儲存時才建立 `machines.json`。執行帳號需能寫入此資料夾，否則顯示儲存失敗並保留原資料。

機台格式維持原本的「分類 → 機台陣列」，沒有新增外層版本欄位、ID 或密碼包裝：

```json
{
    "A": [
        {"name": "加工機10", "ip": "192.0.2.10", "password": ""},
        {"name": "備用機", "ip": "192.0.2.20", "password": ""}
    ],
    "B": []
}
```

使用者設定維持：

```json
{
    "vnc_path": "C:\\Program Files\\uvnc bvba\\UltraVNC\\vncviewer.exe",
    "options": {
        "fullscreen": false,
        "viewonly": false,
        "autoscaling": true
    }
}
```

讀取 UTF-8（可含 BOM）；寫回使用 UTF-8、四格縮排與 LF。既有機台及使用者設定的額外欄位會保留。檔案上限 4 MiB；格式錯誤時停止操作，不以預設資料覆寫原檔。儲存前比對讀入的檔案快照；發現其他程式已修改時要求重新讀取，避免覆蓋對方的修改。

為相容原工具，密碼仍以原本的字串欄位保存。機台清單僅顯示「已設定／未設定」，既有密碼不回傳 WebView。編輯時留空代表保留，填入新值代表更換，勾選「清除已存密碼」才清除。機台資料不送 AI、網站或日誌，實際使用者檔案已加入 Git 忽略規則。

## 機台管理與順序

- 分類按鈕切換機台卡片，點機台卡片才啟動連線。
- 「機台管理」可新增、編輯、移至另一分類及刪除；刪除前會確認。
- 同一分類的機台依 JSON 陣列順序顯示；網站匯入會自然排序本次受影響分類，平常讀取或手動編輯不額外重排。
- 修改既有機台的名稱、IP 或密碼會保留原位置。新增機台或改到另一分類時追加到該分類最後面。
- 管理清單提供「上移／下移」，只調整同一分類內的位置，並直接保存；第一／最後一台對應的移動按鈕停用。
- 管理命令帶清單版次，過期畫面的索引不會誤改或誤連另一台機台。

UI 沿用目前應用程式的主題色、圓角、按鈕與深色模式；卡片隨寬度排列，窄視窗的管理欄位改為上下排列。

## Viewer 啟動

沿用 `user_config.json` 中有效的 `vnc_path`；沒有有效路徑時在標準 Program Files 目錄背景搜尋 `vncviewer.exe`，也可手動指定或重新搜尋。搜尋有 30 秒／20,000 個資料夾上限，略過 reparse point，不掃描任意磁碟。找不到時提供手動指定提示，不自動下載安裝 Viewer。

Rust 直接啟動指定的 `vncviewer.exe`，工作目錄為 Viewer 所在資料夾，參數逐項傳遞；不依賴 Python、CMD、PowerShell、BAT 或 `where`。

參數沿用使用者提供的 Python 工具：有密碼時加入 `/password`，固定 `/shared /autoreconnect 5 /reconnectcounter 3 /quickoption 7`，依勾選加入 `/fullscreen`、`/viewonly`、`/autoscaling`，最後傳 IP／Server。主機支援名稱、IP、`:display` 或 `::port` 形式；不接受夾帶空白或命令選項。

Viewer 自己保存的預設設定也可能影響實際行為；命令列參考 [UltraVNC 官方說明](https://sc.uvnc.com/docs/ultravnc-viewer/52-ultravnc-viewer-commandline-parameters.html)。本程式顯示「已啟動連線」只代表 Viewer 已啟動，實際驗證與遠端連線結果仍由 Viewer 顯示。
