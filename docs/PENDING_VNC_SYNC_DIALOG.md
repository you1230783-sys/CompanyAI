# VNC 網站更新改為對話框

狀態：本文件保留先前 UI 調整的設計與當時驗證紀錄。使用者後續已授權將這批修改納入 0.8.17 EXE 並推送 Git；最新交付範圍及驗證以 [0.8.17 紀錄](VALIDATION_0_8_17.md) 為準。

## 已實作互動

- 在 VNC 快速連線頁面「機台管理」左側新增「從網站更新」按鈕。
- 平時隱藏整個網站更新區塊；點擊按鈕才開啟模態對話框，優先沿用現有 HTML dialog，不新增獨立程序或原生子視窗。
- 帳密、記住／清除密碼、詳細連結設定、取得／停止取得清單、匯入預覽與再次取得清單均集中在對話框內。
- 主頁保留機台分類、連線選項與快速連線清單，日常連線不需要開啟網站更新對話框。
- 開啟對話框只顯示設定，不自動登入或取得清單；使用者明確按下更新才開始。沿用現有帳密保存、清單比較與勾選匯入規則。

## 關閉與狀態處理

- 關閉按鈕、Escape 與點擊外部使用一致的關閉處理；取得中或尚有匯入預覽時，正確停止／捨棄並嘗試登出，不能僅隱藏畫面卻遺留網站 Session。
- 匯入或捨棄後維持既有登出行為；關閉不刪除已儲存機台或已記住的設定。
- 沿用登入與 VNC 啟用門檻；取得期間防止重複請求，重新開啟時狀態一致。
- 對話框可捲動，長清單與較小視窗仍能使用；驗證日常快速連線、機台管理與更新匯入流程。

相關位置：`ui/index.html`、`ui/vnc-sync.js`、`ui/dialogs.js`、`ui/style.css`，必要時同步調整原生 VNC 同步事件處理與自檢。

本機 Edge 預覽已核對：開啟不送登入要求、更新後立即關閉仍送取消、預覽中關閉送取消。取消沿用原生 `cancel_sync` 的停止與登出處理。尚未連接真實機台網站或以新版 EXE 驗收。
