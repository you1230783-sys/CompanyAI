# CAD範例圖

[下載0.8.70雙版分段測試ZIP](cad-segmented-0.8.70.zip)。


這兩份圖由本機Strata Q2透過LM_AI正式代理流程生成，使用低思考、每輪20,000輸出tokens。
2008與2022分開測試，各自生成一張兩層住宅概念圖，並非同一設計的版本轉存。
兩份都已在指定CAD版本存檔、重開、獨立讀回及實際窗口覆核；原始DWG位元未修改。

- 2008/：佑達ICAD2008（Icad.Application.1），九段160項。
- 2022/：浩辰CAD2022（GStarCAD.Application.22）；實際項數見manifest.json。
- manifest.json：DWG的SHA256、分段操作數與已知問題。

分段功能通過不代表圖面設計通過。圖中仍有缺少尺寸、門口／動線與標註等問題，
詳manifest.json；僅供查看模型生成效果與公司端功能比較，不可直接施工或加工。
請以各資料夾對應的CAD版本開啟；2022檔不保證能由2008直接讀取。
