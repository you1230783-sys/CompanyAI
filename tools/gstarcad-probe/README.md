# CAD 獨立測試工具 0.1.1

目標為公司浩辰 CAD 2008／2022 的 COM 相容性實測。工具可列出其他已安裝年份，但**尚未在本機實際 CAD 上驗證繪圖成功**。Solid Edge 不在本次範圍。

## 0.1.1：佑達 ICAD 2008 身份修正

使用者實機已確認 x64 Python 可連接 32 位元 `Icad.Application.1`，應用名稱 ICAD、版本 5.0.20.0。0.1.0 因只認浩辰名稱，在新建文件前停止；這不是繪圖 API 失敗證據。0.1.1 加入此佑達產品的明確身份組合，並核對實際／登錄程式路徑相同；其他未知 ICAD 不直接放行。報告分開記錄 `product_family` 與 `drawing_identity_confirmed`，不將佑達標成浩辰。

此修正只通過本機合成身份與原有幾何自檢；實際繪圖／標註／存檔重開仍待公司測試。重新下載並解壓到新資料夾，確認畫面版本 0.1.1，再執行模式 2、3；不需重裝 CompanyAI。

## 使用方式

1. 完整解壓 `GstarCAD-Probe.zip` 到有寫入權限的本機資料夾；不要在 ZIP 內執行。
2. 先開啟要測的浩辰版本，完成授權／歡迎畫面，不要停留在對話框中。工具與 CAD 使用同一使用者、相同權限層級；通常都用一般權限即可。
3. 執行 `Start-x64.cmd`，確認版本清單。若舊版連線失敗，可再用 `Start-x86.cmd`；兩者獨立回報結果，32位元 CAD 不代表一定必須32位元 Python。
4. 預設選已確認年份最新的版本（2027 > 2026 > … > 2022 > … > 2008），可手動改選。只有內部 ProgID 號碼時標示年份未知，不把 `.27` 當作2027；未知年份排在已知年份之後，再依內部版本排序。失效登錄仍寫入清單報告，但不存在的執行檔不列為可選版本。
5. 先選模式1「唯讀診斷」。成功後再次啟動工具，依序執行模式2「新建圖面」與模式3「增加標註」。2008與2022請分別選取並測試。新版無法連線時不會偷偷改用舊版。

模式2：新建空白文件，設定毫米插入單位，畫200×100矩形與四個直徑10的圓形孔位；這是2D輪廓，不是3D挖孔。

模式3：同樣從新文件開始，再加200、100的線性尺寸及一個直徑10的標註。工具讀回座標、半徑及標註實測值，另存自己的DWG後重開再核對。重開的圖面留給你目視檢查；工具不關閉CAD，也不修改原先開啟的圖面。

若預設範本含模型圖元、單位無法確認、COM身份不符或API不支援，會停止並回報。不自動換版本、不執行CAD命令字串、不修復登錄、不重播失敗的新增操作。空白文件可能因失敗而留在CAD中，請人工確認後關閉。自訂範本的載入行為由CAD本身決定。

## 回傳哪些檔案

`results` 內有：

- `inventory_*.json`：32／64位元COM註冊、候選版本及預設排序。
- 每次測試獨立資料夾內的 `report.json`、`worker.log`、`request.json`。
- 成功繪圖後的 `gstarcad_test.dwg`。

請回傳2008、2022各自的報告，並說明畫面上標註是否正常。報告包含安裝路徑及本工具輸出路徑；不讀取既有圖面正文或列出其檔名。

單次測試最多240秒。逾時只終止本工具Python，CAD內的操作結果可能未知；先檢查CAD，不要直接重按。COM被忙碌／對話框阻擋時，也先回傳錯誤報告。

## 執行環境與驗證界線

包內附獨立 CPython 3.13.12 x64／x86、pywin32 311，不需 pip 或連網；不改 CompanyAI 的分析用 Python，也未將 CAD 自動化接到 AI 工具。Python／pywin32 是上游預編譯品，**不是使用 MSVC v142 本機編譯的產物**；原版授權文件保留在各 runtime 及 wheel 的 dist-info 中。

`local-verification.json` 只證明套件載入、版本排序及合成幾何驗收邏輯通過，不代表2008／2022 COM或DWG已實測。`dependencies.json` 鎖定來源與SHA256，`files-sha256.json` 列出交付檔案雜湊；`rebuild-inputs` 保存離線重建輸入。

維護者可用已安裝的Python執行：

```text
python build_bundle.py --inputs rebuild-inputs --output GstarCAD-Probe.zip
```

資料來源：[GstarCAD官方API](https://www.gstarcad.net/developer/)、[pywin32上游](https://github.com/mhammond/pywin32)。2008／2022 的具體COM方法與版本註冊須以公司實機報告為準。
